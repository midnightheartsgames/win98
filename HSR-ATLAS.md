# Атлас переплетения судеб (HSR 98)

Карта пройденного сюжета: миссии и встречи каждого мира, из которых можно пересмотреть любую сцену или катсцену и ответить в ней иначе. По-английски Fate's Atlas.

## Решения

| Вопрос | Решение |
| --- | --- |
| Название | «Атлас переплетения судеб»; в официальном русском переводе HSR это «Перекрёсток судеб» |
| Бой в пересмотре | Карточка «Бой: {противники}» на 1,5 с, сцена идёт дальше как после победы |
| Побочные сцены | Дорожка «Встречи» в каждом мире, одна встреча — одно место (карта) |
| Неувиденные ветки | Открываются, если увидеть их в пересмотре другим ответом |
| Когда открывается | После знакомства с Экспрессом (`express_intro`), как Путеводитель |

Из оригинала взяты: группировка по мирам, узел = миссия, ветки компаньонов от миссии Освоения, панель узла со статусом, картинкой, пересказом и кнопкой «Пересмотреть», условие открытия у закрытого узла. Не взяты: масштабирование, UID на экране, песочные часы для контента, которого в игре нет.

## Данные

```text
мир (вкладка)    Станция «Герта» · Ярило-VI · Лофу Сяньчжоу · Экспресс · Белзерг   (H.ATLAS_WORLDS)
  глава          H.MISSION_CHAPTERS
    узел миссии  id миссии из H.TRAIL_MISSIONS или H.QUESTS
      эпизод     сюжетная точка { recap, text } в скрипте; id = строка recap
  встречи        meet_<map>: побочные эпизоды одной карты
```

`H.ATLAS`:

- `NODES[id] = { after, thumb, beats }` — 75 узлов миссий. `after` — узел Освоения, от которого отходит ветка компаньона или приключения; `thumb = { cine }` — ролик для миниатюры (средний план, 60% его длины). Без ролика миниатюра — фон места из `H.Cine.STILLS` с портретом `face` миссии.
- `MEETS[id] = { world, map, after, beats }` — 33 места встреч.
- `BRANCH[beat] = from` — эпизод, до которого доходят только другим ответом в эпизоде `from`.
- `PLACE[beat] = [map, mark]` — где запускается эпизод.
- `TEXT` — эпизоды, которые можно только прочитать. Сейчас пусто: все 780 эпизодов проигрываются.

Привязка в инструменте, по порядку правил: шаг `{ quest }` в эпизоде; токен квеста во всех вариантах условия запуска; квест в том же скрипте; флаг завершения миссии Освоения; окно миссии по флагам условия запуска (метки карт, `mate`, `onEnter`, вызовы `{ script }` и `then` у проводки); семейство скриптов (общий префикс имени). Остальное — встречи. Ручные исключения: `OVERRIDES` (для непривязанных) и `FORCED` (исправления) в начале инструмента. Порядок эпизодов внутри узла учитывает зависимости по флагам условий запуска.

Итог: 780 эпизодов, 602 в миссиях, 178 во встречах, 3 ветки. Миссии `pc_guests` и `ks_q5` пустые: в их скриптах нет сюжетных точек.

**После правки сюжета** (новые `recap`, скрипты, миссии, метки): `node tools/hsr-atlas-map.cjs`, затем `node tests/hsr98.test.js`. Тест проверяет свежесть файла, что каждая сюжетная точка лежит ровно в одном узле, что эпизоды из прохождения Ярило-VI лежат в пройденных миссиях и идут в его порядке (допуск 5 пар), и что каждый эпизод проигрывается. Новая миссия должна попасть в главу из `ATLAS_WORLDS[].chapters`, новая глава — в один из миров.

## Статусы

| Узел | Условие | Что видно |
| --- | --- | --- |
| Пройдено | миссия завершена | всё, «Пересмотреть» |
| В процессе | текущая миссия Освоения или начатый квест | название, увиденные эпизоды |
| Закрыто, ближайшее | предыдущий узел дорожки не закрыт (у ветки ещё и `after` пройден) | название, «Откроется после миссии «…».» |
| Закрыто, дальнее | остальное | «???», «Продолжайте Миссии Освоения.» |
| Встреча | хотя бы один эпизод увиден | показывается; иначе только счётчик «Встречи · n из m» |

Эпизод: ✓ увиден (`state.recaps`), ⑂ другая ветка (`from` увиден), ??? не встречен.

`state.atlas = { seen, at, noted }`: открытые узлы (метка «Новое»), последний выбранный узел, показано ли сообщение. Ключ внутри `hsr98.save.*`, `backup-catalog.js` не меняется. `fixAtlas(old)` гасит метки у всего пройденного в старых сохранениях.

## Экран

`ui.openAtlas(node, beat, { fresh })`. Вкладки миров; граф с дорожками приключений, Освоения, компаньонов и встреч; скобки глав со счётом; связи веток с узлом-якорем; полоса глав внизу; справа панель узла (статус, название, глава, кадр, пересказ, участники, эпизоды, «Пересмотреть»). В 16:9 растёт только граф.

| Клавиша | Действие |
| --- | --- |
| ← → | Узел на дорожке |
| ↑ ↓ | Соседняя дорожка |
| Q / E | Мир |
| PgUp / PgDn | Глава |
| Enter | Пересмотреть узел; на закрытом — условие |
| Tab | Список эпизодов: ↑↓, Enter пересматривает с эпизода (у ветки — с эпизода выбора), Tab/Esc назад |
| Esc | Закрыть |

Мышь и касание: клик выбирает, второй клик пересматривает, граф тянется и крутится колесом.

## Пересмотр

`ui.replayBegin(node, beat, back)` → `H.replayGame(home, node, beat)`: копия сохранения, из неё удалены флаги эпизодов этого узла и всех следующих по сюжету (у встречи — только её), сброшены их квесты. Эпизод запускается со своего шага (`runScript(name, { at })`) на карте из `PLACE`. Сюжетная точка того же узла показывает карточку, и сцена идёт дальше; чужая точка, граница входа скрипта или конец скрипта заканчивают эпизод, дальше идёт следующий из очереди.

| Шаг | В пересмотре |
| --- | --- |
| реплики, выбор, ролики, CG, ходьба, музыка, переходы | как в игре |
| `battle` | карточка боя |
| флаги, предметы, отряд, квесты, цели | только во временной игре, тосты и баннеры подавлены |
| `save`, `tut`, `su`, `ui` кроме `doc` | пропуск |
| `magflow`, `carts` | считаются решёнными |
| проводка `lfLeadStart` | сразу сцена `then` |

В настоящее сохранение попадают только впервые увиденные эпизоды: при возврате (`replayEnd`) и при закрытии игры посреди сцены. Пока идёт воспоминание, нельзя сохраниться, уйти в гости, принять приглашение (оно ждёт конца воспоминания), открыть телефон, карту, атаковать. Esc вне диалога, Tab и плашка «Воспоминание · n/m» открывают паузу: «Пропустить эпизод», «Вернуться в атлас», «Смотреть дальше». Отчёт F9 пишет «Атлас: узел / эпизод» и прикладывает настоящее сохранение.

## Точки входа

- Телефон: книга под шестерёнкой в правой колонке (`phoneRail()[4]`), закрыта до `express_intro`, метка «Новое» через `alerts().atlas`.
- Сообщение «Новое в телефоне» один раз после знакомства с Экспрессом.
- База данных: кнопка «Атлас» и клавиша T на хабе (A занята: это «влево» в WASD); «Пересмотреть · Enter» у записей Хроники → Сюжет.
- Обучение: статья `sys_atlas` в разделе «Система».

## Снимки

`node tools/hsr98-shots.cjs <out> atlas atlasmeet atlasreplay` — граф Ярило-VI на «Гнить или гореть», ветка Хук со встречами Камнеграда и список эпизодов, карточка первого эпизода пересмотра.
