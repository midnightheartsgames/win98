# Пароход 98 1.2

Кратко: настоящий лаунчер вместо временной страницы.
Сборка: 
Дата: 29.10.2026

## Новое
- Библиотека с плакатами игр: кадр из игры, строка состояния и одна главная кнопка. Полоса загрузки идёт прямо в кнопке, внизу видно скорость и сколько осталось.
- Страница каждой игры: снимки листаются пальцем и открываются на весь экран, жанр, метки, описание, размер, радио GTA, проверка и удаление файлов.
- «Что нового» для лаунчера и каждой игры, непрочитанные записи выделены.
- Настройки: загрузки по мобильной сети (спрашивать, качать или ждать Wi-Fi), отдача, пульт для левши, прозрачность и размер кнопок в играх, место на телефоне, обновление лаунчера.
- У обновления игры сразу виден размер: считаются только файлы, которых ещё нет на телефоне.
- Список игр есть и при первом запуске без интернета.
- Лаунчер на английском, если телефон на английском, и учитывает крупный шрифт Android.
