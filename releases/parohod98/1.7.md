# Пароход 98 1.7

Кратко: сохранения можно переносить файлом, в том числе с ПК.
Сборка: 
Дата: 30.10.2026

## Новое
- На странице игры появился экран «Сохранения»: размер, «Сохранить в файл», «Загрузить из файла», «Удалить сохранения». Файл открывается и сохраняется через обычное окно выбора Android.
- Прогресс переносится с ПК: Win 98 → «Архивация данных» → файл → телефон. Из общего архива берётся только выбранная игра.
- При удалении игры можно сразу удалить и её сохранения. По умолчанию они остаются.
- В настройках «Место» показывает отдельно файлы и сохранения каждой игры.

## Исправлено
- Маленькие размеры пишутся в КБ, а не «0,0 МБ».
