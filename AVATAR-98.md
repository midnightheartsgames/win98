# Аватар: Тихий цикл — демо (Avatar 98)

2D JRPG в духе 1998–2000 годов (FF7/8/9, Chrono Cross, Suikoden II) во вселенной «Аватара», 174 года после Корры. Демо первой главы — примерно 2 часа: от видения в храме-хранилище и порта Шинрю до крыши Республиканского города и титра «Глава 2: Южный храм воздуха».

Запуск:

- в Win 98: ярлык **Аватар: Тихий цикл** на рабочем столе, меню **Пуск**, команда `avatar` / `silent` в «Выполнить», `C:\Games\Avatar98\SILENT.EXE`;
- отдельно: `http://localhost:8080/avatar98.html` (`?start=new` — сразу новая игра).

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Движение, курсор | стрелки / WASD | крестовина |
| Подтвердить, говорить, осмотреть | Z, Enter, Пробел | A |
| Отмена, назад | X, Esc, Backspace | B |
| Меню | C | Y, Start |
| Бег (инвертируется в настройках) | Shift | X |
| Карманный радиоприёмник / в бою — смена готового персонажа | V, Tab | RB |
| Отладочное меню (только debug-сборка) | F9 | — |

Режим ATB (Active или Wait, по умолчанию Wait — время стоит, пока открыто меню команд) переключается в настройках. Игра встаёт на паузу, когда окно теряет фокус или свёрнуто; экран 320×240 масштабируется целым коэффициентом под размер окна.

## Сборка и проверка

```
npm run build:avatar98          # debug-сборка, F9 включён → js/apps/avatar98/avatar98.js
npm run build:avatar98:release  # минифицированная сборка, отладочное меню вырезано (__DEBUG__ = false)
npm run check:avatar98          # tsc --noEmit, строгая типизация
npm run test:avatar98           # валидация данных + 604 проверки контента, баланса и сохранений
node tests/avatar98.test.mjs --validate   # только загрузка и валидация данных
node tests/avatar98-sim.mjs     # автосимуляция боёв с отчётом по винрейту
```

Тест входит в общий `npm test`. Для тестов нужен Node 22.6+ (TypeScript-исходники запускаются напрямую).

## Архитектура

Код — TypeScript без движков и без зависимостей в рантайме, собирается esbuild в один IIFE-бандл (`window.Avatar98`). Весь контент — JSON в `content/avatar98/`, код его только интерпретирует. Графика и звук генерируются кодом при запуске: пиксельный буфер с sel-out обводкой, генератор персонажей 16×32 по «лукам», портреты 48×48 с пятью эмоциями, ~60 генераторов тайлов, трекерный секвенсор на Web Audio.

## Сохранения

- Сохраняться можно только у святилищ (объект `shrine`). Три слота: `localStorage["avatar98-slot-N"]`.
- «Экспорт в .SAV» в меню слотов пишет файл `ISA_SLOTN.SAV` (чистое сохранение после финала — `ISA_CH2_READY.SAV`) в «Мои документы» (вне Win 98 — скачивание). Формат: строка `AVATAR98SAV v1 <контрольная сумма FNV-1a>` и base64-JSON состояния.
- Импорт: пункт «Импорт файла .SAV» (список из «Моих документов» или файл с диска) либо двойной щелчок по .SAV в Проводнике.
- Поражение в бою → экран «Продолжить / Титульный экран». После финала предлагается чистое сохранение для главы 2.

## Контент демо

| Требование | Реализовано |
|---|---|
| Карты | 24: Шинрю 6 + хранилище видения, шахты 3, паром 2, доки 4, крыши 2 + финальная крыша, станция 5 |
| Враги | 9 обычных, 1 редкий, 2 босса (капитан Роу, Гончая в двух фазах), 1 обучающий, секретный босс — дух-страж |
| Техники | Иса 9, Тао 7, Мири 6, Аватар 1 (Вспышка цикла) + «Каменный шаг» в финале |
| Предметы | 14 расходников, 12 экипировки, 8 Знаков, 6 ключевых |
| Диалоги | ~600 реплик, 12 катсцен, 4 побочных квеста |
| Мини-игры | пай шо «Быстрая раздача» (3 соперника, коллекционные фишки), радио (4 станции, одна открывает тайную комнату) |
| Секреты | 8 тайников, секретный босс |
| Музыка и звук | 12 зацикленных треков, 40+ эффектов |

Баланс проверяется тестами: без гринда партия приходит к Роу на 4–5 уровне, к Гончей — на 9–10; винрейт боёв считается автосимуляцией.

## Как добавить контент

Все ссылки между файлами проверяет `validate.ts` при загрузке и `npm run test:avatar98`, поэтому опечатка в id сразу даёт понятную ошибку.

### Карту

1. Создайте `content/avatar98/maps/<id>.json`:
   ```json
   {
     "id": "rc_bridge", "name": "map.rc_bridge", "w": 20, "h": 15,
     "music": "city_day", "region": "republic", "bg": "#000000",
     "legend": { "B": "planks" },
     "layers": { "ground": ["....20 символов...."], "over": [] },
     "spawns": { "west": { "x": 1, "y": 7, "dir": "right" } },
     "entities": [
       { "id": "to_plaza", "kind": "warp", "x": 0, "y": 7, "to": { "map": "docks_plaza", "spawn": "bridge", "dir": "left" } }
     ]
   }
   ```
   Символы слоёв берутся из `legend` карты, затем из общей легенды `data/tiles.json`. Объектные тайлы (столы, бочки, окна) автоматически поднимаются в слой deco.
2. Добавьте путь в `manifest.json → maps` и строку `map.rc_bridge` в `lang/ru/*.json`.
3. Поставьте обратный `warp` и спавн на соседней карте.

Типы объектов (`kind`): `npc`, `chest`, `warp`, `door`, `trigger`, `enemy` (видимый враг: `troop`, `chase`, `move`), `inspect`, `switch`, `shrine`, `vines` (для Пипо), `hazard` (`steam|spark|searchlight|crumble`), `prop`, `hidden` (тайник). Любой объект принимает `if` — условие появления, и `event` или встроенный `script`.

### Карту в Tiled

1. В игре нажмите F9 → «Экспорт тайлсета PNG» — получите `avatar98_tiles.png`, тайлы 16×16 в порядке `data/tiles.json`.
2. В Tiled создайте карту 16×16, встройте тайлсет (внешние .tsx не поддерживаются). Порядок тайлов совпадает с `tiles.json`; можно также задать тайлу свойство `tile` или класс с явным id.
3. Слои плиток: `ground` (обязателен), `deco`, `over`. Объектный слой: объекты с классом `spawn` (имя = id спавна, свойство `dir`) или с классом, равным `kind` сущности. Свойства объекта копируются как есть; `move`, `to`, `hazard`, `script` пишутся JSON-строкой. Свойства карты: `name`, `music`, `region`, `bg`.
4. Сохраните как `.tmj` в `maps/` и добавьте в манифест. Пример — `maps/ferry_deck.tmj`.

### Врага

1. `data/looks.json` — внешний вид (гуманоид по параметрам или генератор существа).
2. `data/enemies.json`:
   ```json
   { "id": "sewer_eel", "name": "Сточный угорь", "families": ["beast"], "level": 8,
     "stats": { "hp": 420, "mp": 20, "atk": 30, "def": 18, "mag": 12, "res": 14, "spd": 20, "lck": 5 },
     "exp": 90, "gold": 40, "drops": [{ "item": "salve", "chance": 0.3 }],
     "look": "eel", "scan": "scan.sewer_eel",
     "ai": [{ "use": "attack", "weight": 3 }, { "use": "e_bite", "weight": 1, "if": "hpPct<50" }] }
   ```
   Множители стихий — `elem` (плюс общие по `families` в `data/elements.json`), иммунитеты — `statusImmune`, добыча для кражи Мири — `steal` и `rare`, фазы боссов — `phases`, флаг `boss`. Условия AI: `hpPct`, `mpPct`, `turn`, `phase`, `allies`, `foes`, `partyLow`, `status.<id>`, `rand`.
3. `data/troops.json` — отряд `{ "id": "t_sewer", "enemies": [{ "enemy": "sewer_eel" }], "bg": "tunnel" }`.
4. На карте — сущность `enemy` с `troop`, либо команда `{"battle": "t_sewer"}` в событии.

### Технику

Добавьте запись в `data/techniques.json`:

```json
{ "id": "ember_rain", "name": "Дождь углей", "desc": "Огонь по всем врагам.",
  "user": "isa", "group": "flame", "learn": { "level": 11 }, "cost": { "mp": 12 },
  "target": "enemies", "effects": [{ "type": "damage", "element": "fire", "power": 0.8, "stat": "mag" }],
  "fx": "fire_fist", "sfx": "fire1", "anim": "cast" }
```

Изучение — по уровню (`learn.level`), по флагу или командой события `{"learn": {...}}`. Эффекты: урон, лечение, статус, бафф, снятие статусов, кража, Опора и др. — см. `EffectDef` в `data/types.ts`. Техника врага — такая же запись с `"user": "enemy"`.

### Главу

1. `data/chapters.json`: `{ "id": "ch2", "name": "Глава 2: Южный храм воздуха", "flag": "chapter2_unlocked" }` — у предыдущей главы `"next": "ch2"`.
2. Карты главы, события в новом `events/<глава>.json`, строки в `lang/ru/<глава>.json`, всё — в манифест.
3. Узел карты мира в `data/world.json` с условием `if` на флаг главы (узел «Южный храм воздуха» уже заготовлен и откроется, когда флаг будет выставлен).
4. Новые флаги — в `FLAGS.md` (тест проверяет, что каждый используемый флаг задокументирован и где-то выставляется).

### События и диалоги

Событие — массив команд. Реплика: `"tao:smile|Текст"` (говорящий из `data/speakers.json`, эмоция `normal|happy|sad|angry|surprised`) или ключ строки. Основные команды: `talk`, `choice`/`opt`, `if`, `flag`/`unflag`, `set`/`add`, `give`/`take`, `gold`, `battle`, `move`, `face`, `actor`, `camera`, `fade`, `shake`, `caption`, `letterbox`, `music`, `sfx`, `warp`, `join`/`leave`, `trust`, `quest`, `learn`, `shop`, `inn`, `save`, `paisho`, `radio`, `worldmap`, `vision`, `avatar`, `title`, `ending`, `cleansave` — всего 60, полный список в `game/events.ts`.

Условия (`if`): `flag`, `!flag`, `var.x>=2`, `item.jade_key`, `trust.tao>=3`, `quest.lanterns>=2` (номер текущего шага квеста; выполнен — больше числа шагов), `party.miri`, `paisho.wins>=3`, `radio.<станция>`, `lvl.isa>=10`, `visited.<карта>`, с `&&`, `||`, скобками.

## Отступления от ТЗ

- **Ассеты.** Готовых спрайтов, тайлсетов и музыки нет, поэтому вся графика, портреты, шрифт, 12 треков и 40+ звуков генерируются кодом из JSON-описаний. Стиль и разрешение соответствуют ТЗ, сторонние файлы не нужны.
- **Английский язык.** Переведены весь интерфейс и пролог; остальные реплики сюжета при выборе английского показываются на русском. Добавить перевод — положить `lang/en/<глава>.json` с теми же ключами и указать его в манифесте.
- **Комментарии в коде.** Правила проекта (AGENTS.md) запрещают комментарии в исходниках, поэтому код документирован этим файлом, `FLAGS.md`, именами и типами.
- **Длительность.** Около 2 часов при обычном прохождении с побочными квестами; при прямом прохождении — около 1–1,5 часа.
