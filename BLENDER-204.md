# Blender 2.04

Клон Blender 2.04 (Not a Number, октябрь 2000) для Win98-клона. Весь интерфейс рисуется программно на одном canvas: собственный растеризатор с координатами как в OpenGL (начало внизу слева), линии Брезенхэма с пунктиром, треугольники с z-буфером. Оформление взято из настоящего `Blender.exe` из `content/blender2.04-windows/`: заставка, лист иконок кнопок, векторный шрифт Bfont и иконка программы извлекаются из exe скриптом, растровые шрифты интерфейса — X11 BDF (helvR08/10/12, helvB12, misc-fixed).

## Как получить

Blender не установлен по умолчанию. Его скачивают с сайта **http://www.blender3d.com** в Internet Explorer:

1. Страница **Download** → одно из трёх зеркал. Файл `blender2.04-windows.exe` (2.9 МБ) появляется в `C:\My Documents\Downloads`.
2. **Run setup** на той же странице (или двойной щелчок по файлу) открывает мастер установки. Он копирует `Blender.exe`, `Python15.dll`, `Readme.txt` и `Copyright.txt` в `C:\Program Files\Blender 2.04`. Тексты Readme и Copyright — оригинальные.
3. После установки появляются ярлык на рабочем столе, пункт **Пуск → Программы → Blender 2.04**, запись в «Установке и удалении программ» и в каталоге 3ADVANCED. Файлы `.blend` открываются двойным щелчком в Проводнике и на рабочем столе.

Отдельная страница для разработки: `blender204.html` (параметр `?nosplash` убирает заставку).

## Что умеет

**Экран и окна.** Неперекрывающиеся окна с делением и слиянием по краям (СКМ/ПКМ по краю), полноэкранный режим CTRL+↑/↓, несколько экранов (CTRL+←/→), шапки сверху или снизу. Типы окон (SHIFT+F4…F12): 3D, IPO, OOPS, кнопки, файлы, изображение, Info с меню File/Edit/View/Tools и настройками пользователя, редактор последовательностей, текстовый редактор, Image Select, звук. Подсказки к кнопкам, всплывающие меню, тулбокс по SPACE, числовой ввод в кнопках.

**3D-окно.** Виды NumPad 1/3/7/0, перспектива/орто, вращение СКМ (трекбол или turntable), панорамирование и зум, локальный вид, 20 слоёв, режимы отображения Bounds/Wire/Solid/Shaded/Textured, 3D-курсор, выделение ПКМ и рамкой (B), привязка (SHIFT+S), трансформации G/R/S с ограничением по осям, сеткой и числовым вводом, родители (CTRL+P), трекинг (CTRL+T), дубликаты (SHIFT+D/ALT+D), объединение (CTRL+J), окно чисел (N).

**Моделирование.** Меши: все примитивы тулбокса, extrude, spin, spin dup, screw, subdivide (обычный, fractal, smooth), remove doubles, beauty fill, fill, flip normals, to sphere, noise, split, separate, скрытие, пропорциональное редактирование (O). S-Mesh (Catmull–Clark) с уровнем в кнопках Edit. Кривые Безье и NURBS, NURBS-поверхности (curve, circle, surface, tube, sphere, donut), выдавливание и фаска кривых, bevel-объекты, 3D-текст встроенным шрифтом Bfont с заливкой букв и отверстий, ALT+C — перевод текста в кривые и кривых в меш. Метаболы (Ball, TubeX/Y/Z, отрицательные). Решётки (lattice) с деформацией детей. Ika-цепочки с решателем CCD. Vertex paint и face select.

**Материалы и рендер (F12).** Тайловый scanline-рендер с OSA 5/8/11/16, Blinn-блик, лампы Lamp/Spot/Sun/Hemi, теневые буферы у Spot (Soft, Bias, размер), ZTransp, гало (звёзды, линии, кольца), туман, звёзды, небо Blend/Real/Paper, контуры (Edge), motion blur, Panorama, Border, Crop, Gamma, Xparts/Yparts. Процедурные текстуры Clouds, Wood, Marble, Magic, Blend, Stucci, Noise и картинки, colorband, координаты Orco/Glob/Object/UV/Normal, маппинг на цвет, нормаль, блик, отражение, альфу, свечение. Превью материала, лампы, текстуры и мира в кнопках. Радиосити. Рендер анимации (ANIM) и просмотр (PLAY), сохранение картинки F3 в Targa/JPEG/PNG.

**Анимация.** IPO-кривые объектов, материалов, ламп, камер и мира (I — вставка ключа), Безье/линейная/константная интерполяция, экстраполяция и цикличность, редактирование ручек в окне IPO. Ключи вершин мешей (I → Mesh, ключи видны в окне IPO), движение по пути с CurveFollow, эффекты Build, Wave и Particles, редактор последовательностей со сценами, картинками и эффектами Cross, Add, Sub, Alpha Over/Under.

**Игровой движок (F8, P).** Свойства объекта Actor, Dynamic, масса, затухание, Fh. Логические блоки: сенсоры Always, Keyboard, Mouse, Touch, Collision, Near, Radar, Property; контроллеры AND, OR, Expression; актуаторы Object (сила, момент, dLoc, dRot, скорости), Constraint, Ipo, Camera, Sound, Property, Edit Object (добавить, удалить, заменить меш, следить), Scene. Связи тянутся мышью между блоками. Игра идёт в 3D-окне с частотой 50 Гц, физика — сферы против статичной геометрии с трением и подъёмом по Fh. ESC выходит из игры и возвращает сцену.

**Файлы.** `.blend` хранится в виртуальной ФС как `BLENDER-v204` + JSON со ссылками между блоками и раскладкой экранов. F1 — загрузка, F2/CTRL+W — сохранение (резервные `.blend1`, `.blend2` по настройке Versions), SHIFT+F1 — Append блоков из другого файла, CTRL+U — свой стартовый файл, CTRL+O — последний файл. Экспорт DXF (SHIFT+F2), VRML 1.0 (CTRL+F2), Videoscape (ALT+W); Videoscape (`3DG1`) открывается через F1 и добавляется мешем в сцену.

**Не сделано.** Интерпретатор Python: контроллер Python и ALT+P в текстовом окне сообщают «Python not available».

## Сайт www.blender3d.com

`js/apps/blender-site.js` + `css/apps/blender-site.css`. Сайт осени 2000 года в стиле Web 1.0: табличная вёрстка шириной 760 px, логотип из заставки 2.04, меню-полоса, левая колонка навигации с блоком «Get Blender», счётчиком посетителей и бейджами, правая колонка с текущей версией, рекламой руководства, подпиской на рассылку и ссылками. Кнопки нарисованы как кнопки интерфейса Blender.

Разделы: новости (5 статей, отдельные страницы), Download (статус установки, зеркала, другие платформы, инструкция, **Previous releases** с Blender 1.60 — его скачивание, установка и запуск работают как раньше), Features, Gallery (шесть картинок рендерятся движком 2.04 прямо при открытии страницы: метаболы, мраморный тор, 3D-текст, тени от Spot, рябь на сетке, гало), Tutorials (первая игра по шагам и таблица клавиш), FAQ, Shop (заказ по факсу), Community, About NaN, Guestbook (записи хранятся в localStorage, дата — текущий день 2000 года). Сайт перерисовывается, когда меняется статус загрузки или установки.

Скрепыш реагирует на сайт (скачать и запустить 2.04, открыть уроки) и на окно Blender 2.04.

## Устройство кода

Модули лежат в `js/apps/blender204/`, все в пространстве имён `B204`, порядок загрузки в `index.html` важен:

| Модуль | Что внутри |
|---|---|
| b2-assets | извлечённые из exe заставка, иконки, Bfont, BDF-шрифты |
| b2-math, b2-gl | векторы и матрицы, растеризатор `B.Raster` |
| b2-data | Main и ID-блоки, конструкторы объектов, стартовый файл |
| b2-ui | кнопки, блоки, всплывающие меню, ввод чисел и текста |
| b2-screen, b2-app | экраны, области и шапки; `B.App`, события и отрисовка |
| b2-mesh, b2-edit, b2-transform, b2-object, b2-toolbox | меши и режим редактирования, трансформации, операции с объектами, тулбокс |
| b2-view3d | 3D-окно: проекции, отрисовка, выделение |
| b2-buts* | окно кнопок по контекстам F4–F10 |
| b2-texture, b2-render, b2-radio | текстуры, рендер, радиосити |
| b2-anim, b2-space-ipo, b2-effects | IPO, ключи, пути, эффекты |
| b2-curve, b2-mball, b2-lattice, b2-subsurf, b2-paint | кривые и текст, метаболы, решётки и Ika, S-Mesh, vertex paint |
| b2-fileops, b2-space-file, b2-scene | файлы и окно файлов, сцены |
| b2-space-* | окна text, oops, image, seq, sound |
| b2-game | логические блоки и игровой движок |

`js/apps/blender204-app.js` — окно Win 98 (`app_blender204`), `css/apps/blender204.css` — его стили.

Ресурсы пересобираются скриптом `python tools/blender204-assets.py --bdf <папка с BDF>` (недостающие BDF скачиваются).

## Проверка

- `node tests/blender204.test.js` — ядро: порядок модулей в index.html, стартовый экран, TAB и тулбокс, отрисовка всех окон и контекстов кнопок, операции с мешами, кривые, текст, метаболы, IPO, выражения, рендер, сохранение и загрузка `.blend`, Videoscape, физика и логические блоки.
- `node tests/blender-site.test.js` — сайт, каталог, установка 2.04 и архивной 1.60.
- `node tools/blender204-shots.cjs <папка> <сценарий.cjs>` — скриншоты в headless Edge через CDP; переменные `B2_PAGE`, `B2_READY`, `B2_SIZE` позволяют открыть весь рабочий стол (`index.html`) вместо отдельной страницы.
