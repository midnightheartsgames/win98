# Half-Life 98 Prototype

Локальный фан-прототип FPS для существующего Win98-клона. Оригинальные модели, текстуры и аудио Half-Life не используются. WebGL, Canvas 2D и синтезированный Web Audio; внешние библиотеки и сетевые загрузки не нужны.

## Запуск

`npm start`, затем `http://localhost:8080`. На рабочем столе есть ярлык **Half-Life 98**, также добавлен пункт в **Пуск → Программы**. Отдельная страница: `http://localhost:8080/half-life.html`.

NEW GAME начинает лабораторию и записывает начальную контрольную точку. CONTINUE восстанавливает **начало уровня**, а не последнюю позицию. При переходе в сектор C сохраняются текущие HP, оба оружия, выбранное оружие, магазин и запас. Неполная перезарядка отменяется. Смерть позволяет повторить контрольную точку. Если localStorage недоступен, новая игра работает, но сохранение недоступно.

## Управление

| Действие | Клавиши |
|---|---|
| Движение / бег | WASD / левый Shift |
| Обзор | Мышь; если браузер запрещает захват — ПКМ + мышь или стрелки |
| Прыжок / приседание | Space / левый Ctrl или C |
| Атака | ЛКМ, отдельное нажатие на выстрел |
| Перезарядка | R |
| Монтировка / пистолет | 1 / 2 |
| Дверь, терминал, подбор | E |
| Аптечная станция | Удерживать E, направив прицел на станцию |
| Пауза | Esc или Game / Esc |

Для хедкрабов направляйте прицел вниз. Жёлтые деревянные ящики и доски разрушаются монтировкой; за попадание отвечает пространственный луч. Аптечки и боезапас подбираются также при приближении. При зарядке вортигонта укройтесь за стеной, оборудованием или закрытой дверью.

## Прохождение

**Лаборатория:** монтировка на полу впереди → автоматическая дверь → хедкраб → зомби в лаборатории → пистолет в Security Storage → заколоченный проход → смешанные бои → вортигонт → зелёный терминал аварийного лифта. Кнопочные двери открываются клавишей E. Для лифта нужны оба оружия и устранение восьми угроз уровня. Служебная дверь ACCESS DENIED не относится к маршруту.

**Сектор C:** технические помещения → склад → вентиляционный отсек с низким проходом → генераторная → охлаждение → турбинный зал → финальная арена. При входе дверь закрывается: сначала два хедкраба и зомби, затем два вортигонта. Между волнами появляются патроны и аптечка. После победы дверь разблокируется, а зелёный терминал включает питание и показывает **SECTOR C ACCESS RESTORED / PROTOTYPE COMPLETE**. Если остались враги в предыдущих комнатах, можно вернуться через разблокированную дверь.

## Устройство

- `js/apps/half-life/core.js`: Damageable, Player, Weapon/Crowbar/Pistol, Enemy и три разновидности, Interactable, Door, Breakable, Pickup, HealthStation, TriggerVolume, SaveManager.
- `world.js`: две карты, столкновения, пространственные попадания, поиск пути по сетке, обнаружение, триггеры, волны и переходы.
- `renderer.js`: низкополигональные модели, текстура шума 128×128 с nearest-фильтрацией, простое освещение граней, туман, частицы, оружие и подписи.
- `audio.js`: синтез звуков и фонового гула; громкость и отключение на паузе.
- `half-life-app.js`: окно Win98, меню, HUD, настройки, ввод, фиксированные подшаги и очистка ресурсов.

Монтировка: 20 урона, 1,7 м, 0,45 с. Пистолет: 14 урона, 17 в магазине, 68 стартового запаса, перезарядка 1,35 с. Хедкраб: 14 HP; зомби: 60 HP; вортигонт: 80 HP и 0,9 с предупреждения перед лучом. Скорости игрока: 4,5 / 6,5 м/с; прыжок около 1,1 м.

## Проверки и границы версии

`npm run test:half-life` — детерминированные проверки механик без GPU. `npm test` — также существующие проверки Blender и гонок. Проверяются столкновения, урон и прикрытие, повторная перезарядка, разрушение преграды, связность обоих уровней, поведение врагов, валидация сохранения, две финальные волны и вентиляция.

Это компактный игровой срез с процедурными блочными моделями, повторяющейся модульной геометрией комнат и упрощёнными анимациями. Вместо NavMesh используется поиск пути по сетке. Нет полноценной физики предметов, озвученных персонажей и музыкальных композиций; регулятор Ambient drone управляет фоновым гулом. Время прохождения 10–15 минут пока не подтверждено игровым замером. Автоматические проверки переходов и арены не заменяют полное ручное прохождение и настройку сложности.
