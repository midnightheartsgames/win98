# Blender 1.60 Clone

Запуск: `npm start`, затем в **Internet Explorer** перейти на официальный сайт `http://www.blender3d.com` (или через Избранное / поиск), скачать `Setup_Blender160.exe` и выполнить установку через **Blender 1.60 Setup Wizard**. После установки ярлык появится на рабочем столе и в **Пуск → Программы → Blender 1.60**. Зависимостей и сборки нет.

## Управление

- ПКМ выбирает объект или вершину. Shift + ПКМ добавляет/снимает вершину. ЛКМ устанавливает 3D Cursor в плоскости экрана на текущей глубине курсора.
- СКМ вращает вид (trackball), Shift + СКМ панорамирует, Ctrl + СКМ и колесо масштабируют вид.
- G/R/S запускают перемещение/вращение/масштаб. X/Y/Z ограничивают операцию осью мира, повторное нажатие снимает ограничение. ЛКМ или Enter подтверждают; ПКМ или Esc отменяют. Потеря фокуса окна браузера также отменяет операцию.
- Tab переключает Object/Edit. A выделяет всё или снимает выделение. B, затем протягивание ЛКМ, выделяет вершины рамкой насквозь; Shift добавляет.
- В Edit Mode кнопка Faces включает выбор ближайшей грани через ПКМ. E выдавливает выбранную область вдоль усреднённой нормали; движение мыши вправо/вверх задаёт расстояние. Для отдельных вершин без граней используется +Z. Работают осевые ограничения и полная отмена геометрии.
- Space → Add → Mesh → Cube / Plane / UV Sphere / Cylinder добавляет примитив в 3D Cursor. В Edit Mode геометрия добавляется в текущий меш.
- Z переключает Wireframe/Flat Solid. Home центрирует вид на активном объекте. Frame показывает пунктирную рамку формата 4:3 во вьюпорте.
- Buttons: Edit — числовые трансформации объекта и инструменты; Material — цвет; Scene — параметры фиксированного MVP-рендера. Разделитель над Buttons перетаскивается.
- F12 открывает отдельное окно 320×240 с построчным заполнением. Исходная камера смотрит в начало координат; Loc и Rot меняют её положение и направление; источник Lamp влияет на плоское освещение.

## Архитектура

- `MeshModeler`: вершины, рёбра, грани, примитивы, выбор и extrusion региона.
- `Viewport3D`: ортографический интерактивный вид, проекция, picking, сетка, курсор, CPU rasterizer с Z-buffer; перспективный рендер из камеры.
- `ModalStateManager`: снимки состояния, ограничения по осям мира, подтверждение/отмена, преобразование выбранных вершин между локальными и мировыми координатами.
- `BlenderUI`: тайлы, bitmap-подписи, обработчики и хоткеи активного окна, поля, меню и жизненный цикл.
- `AppBlender`: адаптер существующего WindowManager. Закрытие освобождает обработчики, ResizeObserver и таймер; модель остаётся в памяти до перезагрузки страницы.

Это функциональная стилизация, не бинарная совместимость с Blender 1.60. Нет сохранения .blend, общего Undo, текстур, теней и анимации. Viewport использует ортографическую проекцию. Пунктирная рамка — ориентир формата, не preview фактической камеры. Оптика камеры фиксирована; Scale меняет только размер её каркасного значка. Треугольники, пересекающие ближнюю плоскость, пропускаются. Extrude рассчитан на примитивы и простые выпуклые области. Выделение вершин и рамкой сквозное.

Проверки геометрии и модальных операций: `node tests/blender.test.js`.

Браузерный сценарий: `node tests/blender.browser.cjs` (нужны Playwright и Edge; путь к пакету Playwright можно задать переменной `BLENDER_PLAYWRIGHT`). Он проверяет запуск, навигацию мышью, курсор, выбор, отмену, меню, поля, рендер, сворачивание и повторное открытие. Скриншоты: `tests/blender-ui.png` и `tests/blender-render.png`.
