# Win 98 Web Edition + Wolfenstein 3D + LucasArts SCUMM Quest

Интерактивный веб-клон операционной системы **Win 98**, созданный на чистом стеке **HTML5, CSS3 и Vanilla JavaScript** (без сторонних библиотек и фреймворков), с поддержкой ретро-игр, синтезатора звука Web Audio API и файловой системы.

---

## 📁 Где находятся файлы проекта

Проект расположен на вашем диске по пути:
```
C:\Users\MYPC\.gemini\antigravity\scratch\win98-clone
```

Вы можете переместить эту папку в любое удобное место (например, на Рабочий стол или в `D:\Projects\win98-clone`).

---

## 🚀 Как открыть и запустить проект

### 1. Открыть как рабочую область в редакторе (VS Code / Antigravity)
1. В верхнем меню выберите **File > Open Folder...** (Файл > Открыть папку...).
2. Укажите папку `C:\Users\MYPC\.gemini\antigravity\scratch\win98-clone`.
3. Теперь вся кодовая база и будущие сессии чата будут привязаны напрямую к этому проекту.

### 2. Запуск локального сервера
В терминале внутри папки проекта выполните:
```bash
node server.js
```
или
```bash
npm start
```

Затем откройте в браузере:
👉 **http://localhost:8080**

## 🕹️ Что реализовано в проекте

### 1. Рабочий стол и оконный менеджер Win 98
- Аутентичные 3D-бордеры, палитра `#008080`, серо-синие панели, винтажные шрифты и скроллбары.
- Окна с перетаскиванием, минимизацией, максимизацией/восстановлением и закрытием.
- Панель задач (Taskbar) снизу, часы реального времени, трей с регулятором звука и тумблером CRT-фильтра (сканлайны).
- Меню «Пуск» (Start) с вложенными подменю (*Programs, Accessories, Games, Documents, Settings, Find, Help, Run, Shut Down*).
- Выделение рамкой на рабочем столе и контекстное меню правой кнопки мыши (Properties, New Document, Refresh).

### 2. Встроенные приложения
- **Мой компьютер / Проводник (Explorer)**: навигация по дискам `C:` и `D:`, системным папкам и запуск файлов.
- **Блокнот (Notepad)**: сохранение и редактирование файлов в `localStorage` и виртуальной ФС.
- **Paint**: рисование 16 цветами, карандаш, кисть, ластик, заливка (flood fill), геометрические фигуры.
- **Калькулятор**: классический вид со стандартными операциями и памятью.
- **Сапёр (Minesweeper)**: поле 9x9, 10 мин, LED-счётчики, анимированный смайлик.
- **Безмятежность (Bliss)**: стандартная игра, WebGL-полёт над холмом с обоев, пять кадров, альбом, кадр можно сделать обоями (BLISS-98.md).
- **Internet Explorer 5**: браузер в стиле 90-х, портал с бегущей строкой, гифками и работающей Гостевой книгой.
- **Корзина (Recycle Bin)**: очистка с аутентичным звуком шуршания бумаги.
- **Диалог завершения работы**: экран *"It is now safe to turn off your computer"*, перезагрузка и полноэкранный режим **MS-DOS Prompt**.

### 3. Wolfenstein 3D (2.5D Raycaster FPS)
- Полный клон: шесть эпизодов по десять этажей, боссы, тайные этажи и Пак-Ман-лабиринт. Подробности в [WOLF3D.md](WOLF3D.md).
- Рейкастер 320×200 с дверьми посреди клетки, косяками, сдвижными тайными стенами и замками на золотой и серебряный ключ.
- Враги по правилам оригинала: охрана, овчарки, эсэсовцы, офицеры, мутанты и девять боссов; слух через открытые двери, засады, уклонение.
- Меню, выбор эпизода и сложности, интермиссии со статистикой, сохранения, рекорды, код M+L+I.

### 4. LucasQuest 98 (LucasArts SCUMM Adventure)
- Панель из 9 классических глаголов (*Give, Open, Close, Pick up, Look at, Talk to, Use, Push, Pull*).
- Динамическая строка составления действий (*«Use Mug of Hot Java with Sleeping Sysadmin»*).
- Главный герой Гайбраш Байтвуд с плавной походкой.
- 3 интерактивные локации (Серверная 1998 года, Подвальный архив, Крыша с Dial-up спутниковой антенной).
- Головоломки с инвентарём (Резиновая курица, кружка Win 98, загрузочный CD-ROM) и остроумные ветвящиеся диалоги.
- Синтезатор музыки в духе iMUSE / MIDI через Web Audio API.

## Netscape 6 — настоящий интернет в стиле Web 1.0

В систему встроен второй браузер — **Netscape 6** (иконка на рабочем столе и
пункт в «Пуск → Программы»). В отличие от Internet Explorer с вымышленными
сайтами, Netscape ходит в **настоящий интернет** через локальный шлюз и
переписывает любую современную страницу под веб 1998 года.

Требуется запущенный сервер:

```bash
npm start   # node server.js, http://localhost:8080
```

**Как это работает**

Шлюз не вырезает текст из HTML, а пересобирает страницу по тому, как она
на самом деле выглядит. Движок отрисовки открывает сайт в окне 1024x768,
выполняет JavaScript, прокручивает ленивые блоки и снимает «слепок»: для
каждого видимого элемента — координаты, цвет текста и фона, размер и
начертание шрифта, выравнивание, рамки, картинки, ссылки и поля форм.
Из слепка строится страница на HTML 3.2.

| Часть | Файл | Назначение |
|---|---|---|
| Слепок страницы | `js/netscape-snapshot.js` | Сценарий, который выполняется внутри отрисованной страницы и собирает дерево видимых элементов с геометрией и стилями |
| Движок отрисовки | `js/netscape-renderer.js` | Встроенный Chromium приложения Electron или headless Edge/Chrome через DevTools Protocol; очередь из двух вкладок |
| Разбор HTML | `js/netscape-html.js` | Запасной путь без движка: собственный разборщик HTML строит то же дерево, только без координат |
| Перевод в Web 1.0 | `js/netscape-web1.js` | Превращает дерево в HTML 3.2: таблицы, `<font>`, палитра 216 цветов, украшения |
| Шлюз | `js/netscape-proxy.js` | Маршруты сервера, защита от адресов локальной сети, кэш, прокси картинок, формы |
| Браузер | `js/apps/netscape.js` | Окно, меню, история, закладки, журнал, строка состояния |
| Скин | `css/apps/netscape.css` | «Modern»-скин Netscape 6 поверх Win 98 |

Маршруты сервера: `/netscape/page?url=...` — страница, `/netscape/img?url=...&ref=...` — картинка,
`/netscape/form` — отправка GET-формы, `/netscape/status` — какой движок найден.
Параметры страницы: `mode=static` (без JavaScript), `deco=0` (без украшений),
`colors=full` (без палитры 216 цветов), `reload=1` (мимо кэша).

**Что делает шлюз с сайтом**

- Блоки, стоящие рядом (колонки, сетки карточек, боковые панели), становятся
  `<table>` с шириной колонок в процентах; блоки с фоном — таблицами с `bgcolor`,
  с рамкой — `border="1"`; плавающие блоки — `align="left|right"`.
- Ряд коротких ссылок (меню, хлебные крошки, теги) становится строкой `Ссылка | Ссылка | Ссылка`.
- Размер шрифта переводится в `<font size="1..7">`, цвет — в `<font color>`,
  жирный и курсив — в `<b>` и `<i>`, моноширинный текст — в `<tt>`. Крупный
  короткий текст становится `<h1>`–`<h3>` по тому, как он выглядит, а не по тегу.
- Цвета округляются до палитры из 216 безопасных цветов; нечитаемые сочетания
  текста и фона исправляются на чёрный или белый.
- Картинки уменьшаются под 800x600 и проходят через фильтр с дизерингом и
  палитрой 216 цветов, как GIF того времени. SVG-логотипы сохраняются.
- Ссылки внутри страницы (`#раздел`) работают через `<a name>`.
- GET-формы (поиск по YouTube, Википедии, DuckDuckGo) работают через `/netscape/form`;
  POST-формы показываются, но поля в них отключены.
- Встроенные видео YouTube превращаются в рамку с превью и ссылкой на ролик.
- Внизу — украшения 1998 года: бегущая строка с описанием сайта, счётчик
  посетителей, дата обновления, «Лучше всего смотреть в Netscape 6 при 800x600»
  и кнопки 88x31.
- Всплывающие окна cookie, рекламные блоки, скрытые и невидимые элементы,
  карусели за краем экрана в слепок не попадают.
- Все ссылки и картинки идут обратно через шлюз — сёрфить можно бесконечно.
  Последние 40 страниц хранятся в кэше 10 минут, поэтому «Назад» срабатывает сразу.
- Запросы во внутреннюю сеть (localhost, 10.x, 192.168.x и т. п.) блокируются,
  в том числе после перенаправлений и внутри движка отрисовки.
- Ссылки-прокладки поисковиков (`duckduckgo.com/l/?uddg=…`, `google.com/url?q=…`) разворачиваются в настоящий адрес.
- Картинки, текстовые файлы и прочие файлы по прямой ссылке показываются отдельными страницами.

Движок отрисовки: в приложении Electron используется его собственный Chromium,
при `npm start` — установленный Edge или Chrome (путь можно задать через
`NETSCAPE_BROWSER`). Если движка нет, страница собирается из исходного HTML.
Меню «Вид»: «Выполнять JavaScript», «Украшения 1998 года», «Палитра 216 цветов»;
«Исходный код страницы» открывает получившийся HTML 3.2 в Блокноте.

Адресная строка понимает и адреса, и поисковые запросы: текст без домена уходит
в поиск DuckDuckGo. Внутренние страницы: `about:netscape` (стартовая),
`about:bookmarks`, `about:history`.

## Steam — покупка и загрузка игр

Игры проекта не установлены в системе изначально. Их покупают и загружают в клиенте **Steam** («каким он был бы в 2000 году»).

1. Откройте Internet Explorer и перейдите на `http://www.steampowered.com`, нажмите «Загрузить Steam».
2. Запустите `SteamInstall.exe` из окна загрузки или из «Мои документы\Downloads» и пройдите мастер установки.
3. В Steam откройте «Игры»: раздел «Магазин Steam» — каталог, «Мои игры» — библиотека. Кнопка «Подробнее» открывает страницу игры: жанр, метки, описание и два снимка экрана; щелчок по снимку открывает его в размере 640×480.
4. Платные игры оплачиваются картой из файла «Банковская карта и сайты.txt» (промокоды WIN98SE и CYBER1998 дают 20%), бесплатная Honkai: Star Rail 98 добавляется кнопкой «Получить».
5. Steam сам загружает игру (скорость зависит от типа подключения в «Настройках»), кладёт её в `C:\Games` и создаёт ярлыки на Рабочем столе и в меню «Пуск».

Окна клиента: «Игры», страница игры («Подробнее») и просмотр снимков, «Покупка», «Обновление <игра>», «Монитор» (график сети, пауза, ограничение скорости), «Друзья» с перепиской, «Серверы», «Настройки», «Новости». Код: `js/apps/steam.js`, `js/apps/steam-site.js`, стили `css/apps/steam.css`, `css/apps/steam-site.css`, тест `node tests/steam.test.js`.

Жанр, метки и подписи к снимкам хранятся в записи игры в `js/game-manager.js` (`genre`, `tags`, `shots`), сами снимки — в `content/steam/<id>-1.jpg`, `<id>-2.jpg` (640×480). Их снимает из настоящих игр команда `node tools/steam-shots.cjs [id ...]` (headless Edge) по рецептам из `tools/steam-shots-recipes.cjs`; после пересъёмки сверьте подписи со снимками.

Демоверсии с диска «Игромания» ставятся с компакт-диска (`D:\demo`) его мастером установки, в Steam их нет: NHL 98, Burnout, World Cup 98 и семнадцать игр проекта (LucasQuest 98, Fallout 98, Half-Life 98, Half-Life 2, Midnight Glide, Heroes of Might and Magic 98, Tekken 98, S.T.A.L.K.E.R. 98, Minecraft 98, Sam & Max: Moai Better Blues, KOTOR 98, XIII, Devil May Cry 98, Корованы, Dragon Age: Origins 98, Max Payne, Fallout: Запорожье). Если такая игра не установлена, система показывает путь к демоверсии на диске.

## Скрепыш — помощник Office 97

Скрепыш живёт в правом нижнем углу и следит за всей системой: реагирует на программы, игры и сайты, помогает с письмами и отвечает на вопросы.

- **Спросить:** F1 на рабочем столе, «Что вы хотите сделать?» в его меню или `clippy вопрос` в сеансе MS-DOS. Ответы открывают нужные программы, сайты и разделы справки.
- **Советы:** если рядом с ним мигает лампочка (и значок на иконке в трее), у него есть совет. Щёлкните, когда будет время.
- **Письма:** начните текст в Блокноте или WordPad со слов «Уважаемый» или «Привет», и появится Мастер писем. Он же помогает в новом сообщении Outlook Express.
- **Параметры помощника** (правая кнопка по Скрепышу): «Коллекция» его коллег и настройки — о чём молчать, звуки, F1, лампочка, назойливость. Настройки видны в реестре (`HKEY_CURRENT_USER\Software\Microslop\Office\8.0\Common\Assistant`) и в «Настройке системы» как ClippyOffice.
- **Система:** `clippy.exe` в Диспетчере задач, контакт в ICQ (UIN 199898), папка `C:\Program Files\Microslop Office\Office\Actors`, письма от него в Outlook Express, команда `clippy` в окне «Выполнить».
- **История:** девять глав про Office 2000, пса Rocky и Office XP открываются в разговорах со временем.

Дизайн персонажа, мир, тема и карта интеграций — в [CLIPPY.md](CLIPPY.md). Проверка: `npm run test:clippy`.

## Лаунчеры и обновления

**Для игрока.** `Win98.exe` сначала открывает лаунчер в окне Win 98: какая версия стоит, есть ли новая и что в ней, новости проекта. «Обновить» качает только изменённые файлы, архив Win98.zip заново скачивать не нужно; «Запустить Win 98» открывает систему. Отложенное обновление напомнит о себе значком в области уведомлений. `StarRail98.exe` (Star Rail 98 для ПК) открывает лаунчер в стиле сайта игры: маршрут версий, «Билет на Экспресс», новости. В APK есть пункт «Обновления» в главном меню. Сохранения при обновлениях не меняются.

**Для разработчика.** Выпуск одной командой: `npm run release -- win98` или `npm run release -- sr98` (по умолчанию канал test, потом `npm run release -- promote <продукт> <версия>`). Тексты «Что нового» лежат в `releases/<продукт>/next.md`. Файлы обновлений подписаны ключом `%USERPROFILE%\.win98-release.key` и раздаются с мини-ПК (`https://pennygachi.men/web98/update/`). Устройство системы, форматы и этапы — в [LAUNCHER.md](LAUNCHER.md). Тесты: `npm run test:updater`, `npm run test:release`, `npm run test:hsr98-update`.

## Пароход 98: игры на Android

**Для игрока.** Пароход 98 — бесплатное приложение для телефона с Android 8.0 и новее. В нём Forza Horizon: Рига, Grand Theft Auto: Нижний Сити и Serious Sam 98 с управлением для сенсорного экрана. Файл APK лежит на странице Win 98 и на сайте Star Rail 98. Игры скачиваются и обновляются внутри приложения, радио GTA качается отдельно. Экран «Сохранения» на странице игры переносит сохранения файлом: с ПК через «Архивацию данных» в Win 98, а с телефона обратно через «Открыть файл...» в том же окне.

**Для разработчика.** Устройство, форматы, этапы и замеры — в [ANDROID-LAUNCHER.md](ANDROID-LAUNCHER.md), как добавить игру и как выпускать — в разделе про Android в `AGENTS.md`. Выпуск: `npm run release -- parohod98 games` и `npm run release -- parohod98`, в stable через `promote parohod98 <apk|игра> <версия>`. Тесты: `npm run test:parohod98`. ## Отчёты об ошибках (F10, Ctrl+F10, F9)

**Для игрока.** Заметили ошибку — нажмите **F10**. В Fallout и «Другой войне» F10 занята самой игрой, там и везде работает **Ctrl+F10**. Окно «Сообщение об ошибке» уже содержит снимок экрана и строку «Где» (окно, адрес в IE, папка в Проводнике, место в игре). Достаточно написать одну строку в «Что случилось?» и нажать «Отправить». Рамкой можно пометить место ошибки, чёрным прямоугольником — скрыть лишнее. Пароли и набранный текст в отчёт не попадают; точное содержимое показывает кнопка «Показать данные».

- Номер отчёта (`BR-ГГММДД-XXXX`) виден сразу. Статус («Получен», «Принят», «Исправлен в версии…») показывают «Мои отчёты» (Пуск → Программы → Стандартные → Служебные, или `bugreport /list` в «Выполнить»). Когда отчёт исправлен, в трее появляется значок.
- Без интернета отчёт сохраняется и уходит сам при следующем запуске. Кнопка «В файл...» сохраняет `BR-....bugreport.json`, его можно передать разработчику вручную.
- Если программа упала, система сама предложит отправить отчёт («Программа выполнила недопустимую операцию»).
- В **Honkai: Star Rail 98** есть своё окно в стиле игры по **F9** (в standalone-версии и APK — кнопка «Баг» на сенсорной панели). Оно прикладывает текущее состояние игры, включая несохранённый прогресс.

**Для разработчика.** Отчёты игроков принимает сервер на мини-ПК (`https://pennygachi.men/api/bugs`, `tools/bugs/receiver.cjs`) и присылает их в Telegram с кнопками статуса. Запуск из репозитория (`npm start`, `npm run app`) пишет свои отчёты прямо в папку `bugreports/` (она не попадает в git и в exe).

```
node tools/bugs.cjs pull                     забрать новые отчёты и статусы с сервера
node tools/bugs.cjs list --status new        список
node tools/bugs.cjs show BR-261027-7K3Q      report.md
node tools/bugs.cjs status BR-261027-7K3Q fixed --in next --note "..."
node tools/bugs.cjs serve                    страница разбора на http://127.0.0.1:8099
node tools/bugs.cjs repro BR-261027-7K3Q     система на порту 8091 с сохранением из отчёта
```

Для `pull` и `status` нужен токен сервера в `%USERPROFILE%\.win98-bugs.json` (`{"token": "..."}`). Устройство системы, формат отчёта, сервер и этапы — в [BUGREPORT.md](BUGREPORT.md). Тесты: `npm run test:bugreport`, `npm run test:hsr98-bug`.
