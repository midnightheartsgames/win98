# Win 98 Web Edition + Wolfenstein 3D + LucasArts SCUMM Quest

Интерактивный веб-клон операционной системы **Win 98**, созданный на чистом стеке **HTML5, CSS3 и Vanilla JavaScript** (без сторонних библиотек и фреймворков), с поддержкой ретро-игр, синтезатора звука Web Audio API и файловой системы.

---

## 📁 Где находятся файлы проекта

Проект расположен на вашем диске по пути:
```
C:\Users\MYPC\.gemini\antigravity\scratch\win98-clone
```

Вы можете переместить эту папку в любое удобное место (например, на Рабочий стол или в `D:\Projects\win98-clone`).

---

## 🚀 Как открыть и запустить проект

### 1. Открыть как рабочую область в редакторе (VS Code / Antigravity)
1. В верхнем меню выберите **File > Open Folder...** (Файл > Открыть папку...).
2. Укажите папку `C:\Users\MYPC\.gemini\antigravity\scratch\win98-clone`.
3. Теперь вся кодовая база и будущие сессии чата будут привязаны напрямую к этому проекту.

### 2. Запуск локального сервера
В терминале внутри папки проекта выполните:
```bash
node server.js
```
или
```bash
npm start
```

Затем откройте в браузере:
👉 **http://localhost:8080**

## 🕹️ Что реализовано в проекте

### 1. Рабочий стол и оконный менеджер Win 98
- Аутентичные 3D-бордеры, палитра `#008080`, серо-синие панели, винтажные шрифты и скроллбары.
- Окна с перетаскиванием, минимизацией, максимизацией/восстановлением и закрытием.
- Панель задач (Taskbar) снизу, часы реального времени, трей с регулятором звука и тумблером CRT-фильтра (сканлайны).
- Меню «Пуск» (Start) с вложенными подменю (*Programs, Accessories, Games, Documents, Settings, Find, Help, Run, Shut Down*).
- Выделение рамкой на рабочем столе и контекстное меню правой кнопки мыши (Properties, New Document, Refresh).

### 2. Встроенные приложения
- **Мой компьютер / Проводник (Explorer)**: навигация по дискам `C:` и `D:`, системным папкам и запуск файлов.
- **Блокнот (Notepad)**: сохранение и редактирование файлов в `localStorage` и виртуальной ФС.
- **Paint**: рисование 16 цветами, карандаш, кисть, ластик, заливка (flood fill), геометрические фигуры.
- **Калькулятор**: классический вид со стандартными операциями и памятью.
- **Сапёр (Minesweeper)**: поле 9x9, 10 мин, LED-счётчики, анимированный смайлик.
- **Internet Explorer 5**: браузер в стиле 90-х, портал с бегущей строкой, гифками и работающей Гостевой книгой.
- **Корзина (Recycle Bin)**: очистка с аутентичным звуком шуршания бумаги.
- **Диалог завершения работы**: экран *"It is now safe to turn off your computer"*, перезагрузка и полноэкранный режим **MS-DOS Prompt**.

### 3. Wolfenstein 3D (2.5D Raycaster FPS)
- Полный клон: шесть эпизодов по десять этажей, боссы, тайные этажи и Пак-Ман-лабиринт. Подробности в [WOLF3D.md](WOLF3D.md).
- Рейкастер 320×200 с дверьми посреди клетки, косяками, сдвижными тайными стенами и замками на золотой и серебряный ключ.
- Враги по правилам оригинала: охрана, овчарки, эсэсовцы, офицеры, мутанты и девять боссов; слух через открытые двери, засады, уклонение.
- Меню, выбор эпизода и сложности, интермиссии со статистикой, сохранения, рекорды, код M+L+I.

### 4. LucasQuest 98 (LucasArts SCUMM Adventure)
- Панель из 9 классических глаголов (*Give, Open, Close, Pick up, Look at, Talk to, Use, Push, Pull*).
- Динамическая строка составления действий (*«Use Mug of Hot Java with Sleeping Sysadmin»*).
- Главный герой Гайбраш Байтвуд с плавной походкой.
- 3 интерактивные локации (Серверная 1998 года, Подвальный архив, Крыша с Dial-up спутниковой антенной).
- Головоломки с инвентарём (Резиновая курица, кружка Win 98, загрузочный CD-ROM) и остроумные ветвящиеся диалоги.
- Синтезатор музыки в духе iMUSE / MIDI через Web Audio API.

## Netscape 6 — настоящий интернет в стиле Web 1.0

В систему встроен второй браузер — **Netscape 6** (иконка на рабочем столе и
пункт в «Пуск → Программы»). В отличие от Internet Explorer с вымышленными
сайтами, Netscape ходит в **настоящий интернет** через локальный шлюз и
переписывает любую современную страницу под веб 1998 года.

Требуется запущенный сервер:

```bash
npm start   # node server.js, http://localhost:8080
```

**Как это работает**

| Часть | Файл | Назначение |
|---|---|---|
| Шлюз Web 1.0 | `js/netscape-proxy.js` | Качает страницу, вырезает JS/CSS/фреймы, переводит разметку в теги 1998 года, проксирует картинки |
| Движок JS | `js/netscape-renderer.js` | Для SPA (YouTube и т.п.) открывает страницу в headless Edge/Chrome через DevTools Protocol и забирает готовый DOM |
| Браузер | `js/apps/netscape.js` | Окно, меню, история, закладки, журнал, строка состояния |
| Скин | `css/apps/netscape.css` | «Modern»-скин Netscape 6 поверх Win 98 |

Маршруты сервера: `/netscape/page?url=...` — страница, `/netscape/img?url=...` — картинка.

**Что делает шлюз с сайтом**

- Times New Roman, серый фон в полоску, синие подчёркнутые ссылки, `<hr>`.
- Таблицы с рамками вместо flex/grid; `<center>`, `<tt>`, `<blockquote>`.
- Синяя «шапка» с названием сайта, бегущая строка, мигающее `NEW!`.
- Счётчик посетителей, «UNDER CONSTRUCTION», «Best viewed at 800x600».
- Все ссылки и картинки перенаправляются обратно в шлюз — сёрфить можно бесконечно.
- Запросы во внутреннюю сеть (localhost, 10.x, 192.168.x и т. п.) блокируются.
- Если без JavaScript на странице пусто, шлюз сам отрисовывает её в headless-браузере
  (Edge или Chrome; путь можно задать через `NETSCAPE_BROWSER`). Режим меняется в меню
  «Вид → JavaScript: автоматически / всегда / отключить».
- Ссылки-прокладки поисковиков (`duckduckgo.com/l/?uddg=…`, `google.com/url?q=…`) разворачиваются в настоящий адрес.
- GET-формы (поиск по YouTube, Википедии, HN) работают через `/netscape/form`.
- У видео и медиа-страниц сверху выводится карточка из OpenGraph: превью, заголовок, описание.

Адресная строка понимает и адреса, и поисковые запросы: текст без домена уходит
в поиск DuckDuckGo. Внутренние страницы: `about:netscape` (стартовая),
`about:bookmarks`, `about:history`.

## Steam — покупка и загрузка игр

Игры проекта не установлены в системе изначально. Их покупают и загружают в клиенте **Steam** («каким он был бы в 2000 году»).

1. Откройте Internet Explorer и перейдите на `http://www.steampowered.com`, нажмите «Загрузить Steam».
2. Запустите `SteamInstall.exe` из окна загрузки или из «Мои документы\Downloads» и пройдите мастер установки.
3. В Steam откройте «Игры»: раздел «Магазин Steam» — каталог, «Мои игры» — библиотека. Кнопка «Подробнее» открывает страницу игры: жанр, метки, описание и два снимка экрана; щелчок по снимку открывает его в размере 640×480.
4. Платные игры оплачиваются картой из файла «Банковская карта и сайты.txt» (промокоды WIN98SE и CYBER1998 дают 20%), бесплатная Fallout 2 Demo добавляется кнопкой «Получить».
5. Steam сам загружает игру (скорость зависит от типа подключения в «Настройках»), кладёт её в `C:\Games` и создаёт ярлыки на Рабочем столе и в меню «Пуск».

Окна клиента: «Игры», страница игры («Подробнее») и просмотр снимков, «Покупка», «Обновление <игра>», «Монитор» (график сети, пауза, ограничение скорости), «Друзья» с перепиской, «Серверы», «Настройки», «Новости». Код: `js/apps/steam.js`, `js/apps/steam-site.js`, стили `css/apps/steam.css`, `css/apps/steam-site.css`, тест `node tests/steam.test.js`.

Жанр, метки и подписи к снимкам хранятся в записи игры в `js/game-manager.js` (`genre`, `tags`, `shots`), сами снимки — в `content/steam/<id>-1.jpg`, `<id>-2.jpg` (640×480). Их снимает из настоящих игр команда `node tools/steam-shots.cjs [id ...]` (headless Edge) по рецептам из `tools/steam-shots-recipes.cjs`; после пересъёмки сверьте подписи со снимками.

Демоверсии с диска «Игромания» (NHL 98, Burnout) по-прежнему ставятся с компакт-диска.

## Скрепыш — помощник Office 97

Скрепыш живёт в правом нижнем углу и следит за всей системой: реагирует на программы, игры и сайты, помогает с письмами и отвечает на вопросы.

- **Спросить:** F1 на рабочем столе, «Что вы хотите сделать?» в его меню или `clippy вопрос` в сеансе MS-DOS. Ответы открывают нужные программы, сайты и разделы справки.
- **Советы:** если рядом с ним мигает лампочка (и значок на иконке в трее), у него есть совет. Щёлкните, когда будет время.
- **Письма:** начните текст в Блокноте или WordPad со слов «Уважаемый» или «Привет», и появится Мастер писем. Он же помогает в новом сообщении Outlook Express.
- **Параметры помощника** (правая кнопка по Скрепышу): «Коллекция» его коллег и настройки — о чём молчать, звуки, F1, лампочка, назойливость. Настройки видны в реестре (`HKEY_CURRENT_USER\Software\Microslop\Office\8.0\Common\Assistant`) и в «Настройке системы» как ClippyOffice.
- **Система:** `clippy.exe` в Диспетчере задач, контакт в ICQ (UIN 199898), папка `C:\Program Files\Microslop Office\Office\Actors`, письма от него в Outlook Express, команда `clippy` в окне «Выполнить».
- **История:** девять глав про Office 2000, пса Rocky и Office XP открываются в разговорах со временем.

Дизайн персонажа, мир, тема и карта интеграций — в [CLIPPY.md](CLIPPY.md). Проверка: `npm run test:clippy`.
