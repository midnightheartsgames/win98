# Пароход 98: лаунчер игр для Android

План от 29.10.2026. Реализация идёт по этапам, один этап за шаг, после каждого этапа нужно одобрение.

Название выбрал автор: «Пароход 98» (`parohod98`), ответы на вопросы записаны в разделе «Решения автора».

Пароход 98 — отдельное приложение для Android (APK). В нём игрок скачивает игры проекта, обновляет их и запускает. Игры не становятся отдельными APK: их файлы лежат внутри лаунчера. Первые три игры: Forza Horizon: Рига, Grand Theft Auto: Нижний Сити и Serious Sam 98. Все три получают управление для сенсорного экрана.

## Зачем

1. Игры проекта есть только внутри Win 98 на ПК. На телефоне сейчас есть только Star Rail 98.
2. Одно приложение на все игры. Лаунчер сам качает файлы игры и сам её открывает, как Steam внутри Win 98.
3. Загрузка по файлам уже работает у Win 98 и Star Rail 98 (`LAUNCHER.md`): сервер, блобы, подписи, каналы test и stable, одна команда выпуска. Лаунчер берёт всё это и не требует нового сервера.
4. Покупок нет. Игры бесплатные, в лаунчере есть только «Скачать», «Играть» и «Обновить».

## Цели, которые можно проверить

- Лаунчер показывает библиотеку меньше чем через 1,5 с после запуска. Список берётся из кэша, проверка идёт в фоне и длится не дольше 8 с. Если сервер не ответил, лаунчер пишет «Нет связи», а скачанные игры запускаются.
- Скачанная игра запускается одним касанием и без интернета.
- Serious Sam 98 (около 0,1 МБ загрузки без шрифтов) готов к игре меньше чем через 10 с после касания «Скачать» при 4G.
- Обновление игры качает только изменённые файлы. Правка кода одной игры обычно весит меньше 1 МБ.
- Обрыв сети, сворачивание, закрытие приложения и перезагрузка телефона посреди загрузки ничего не ломают. При следующем открытии загрузка продолжается с места обрыва, готовые файлы заново не качаются.
- Обновления игр и лаунчера не трогают сохранения.
- Каждое действие игры доступно касанием. Тест сверяет список действий игры с элементами пульта в каждом режиме (пешком, в машине, в меню).
- Кнопка «Назад» Android работает везде и никогда не закрывает игру без вопроса.
- На пресете «Телефон» игра держит частоту экрана телефона (90 или 120 Гц) там, где хватает видеокарты, и не меньше 60 кадров/с на iQOO. На пресете «Слабый телефон» не меньше 25 кадров/с на Tecno.
- Плавность не зависит от частоты кадров: всё, что движется, рисуется между шагами симуляции, и при 90 или 120 кадрах/с ничего не дёргается.
- В лаунчере нет цен, кнопок «Купить» и слов Steam и Valve (Steam ищется отдельным словом, английское имя Steamer 98 разрешено). Это проверяет тест текстов.

## Принципы

- Игра важнее лаунчера. Скачанная игра запускается одним касанием, без связи с сервером. Обновление не обязательное. Исключение одно: новому пакету игры нужна новая версия лаунчера.
- В APK лежит только лаунчер. Игры качаются внутри него и хранятся в его папке.
- Код игры один для Win 98, standalone-страницы и телефона. Телефонные части включаются только флагом `window.Parohod98`. Без флага игра работает как сейчас, это проверяют тесты игр.
- Пульт пишет прямо во ввод игры (`input()`, `buildInput()`), а не изображает клавиатуру. Так руль, стик и взгляд остаются плавными, а не «нажато / не нажато».
- Сенсорный экран не меняет баланс: уровни сложности, урон и ИИ те же. Неточность пальца закрывает помощь во вводе (прицел, автогаз), её можно выключить.
- Окна только для подтверждений: загрузка по мобильной сети, удаление, выход из игры.
- Лаунчер ничего не сообщает об игроке. Он только качает файлы. Отчёт об ошибке уходит, только когда игрок сам его отправил.
- Вид Steam 98: оливковые панели, рамки, золотые заголовки. Раскладка своя: телефон лежит горизонтально, работают большие пальцы, мыши и наведения нет.

## Общая схема

```text
ПК разработчика
  npm run release -- parohod98            APK лаунчера
  npm run release -- parohod98 games      пакеты игр: манифесты, новые блобы, «Что нового»
                                       → указатель канала заливается последним
мини-ПК (статичные файлы, та же папка update/)
  update/parohod98/test.json, stable.json         каталог канала: APK и версии игр, с подписью
  update/parohod98/<игра>/manifest-1.2.json       файлы версии игры
  update/blobs/...                             общие с Win 98 и SR98
телефон
  Пароход 98 → Библиотека → «Скачать» → блобы в files/store/ → «Играть»
          → окно игры (WebView, файлы из store/) → «Выход» → Библиотека
```

## Приложение

### Состав

| Часть | Что делает |
| --- | --- |
| `DownloadService.java` | Служба загрузки с уведомлением: держит загрузку в свёрнутом приложении (В9). |
| `App.java` | Живёт, пока работает приложение. Держит загрузчик, очередь загрузок и кэш каталога. Загрузка не обрывается при переходе из лаунчера в игру. |
| `LauncherActivity.java` | WebView со страницей лаунчера, мост `Parohod98`, обновление APK, файлы сохранений через SAF. |
| `GameActivity.java` | WebView с игрой, мост `Parohod98Game`, «Назад», сворачивание, падение страницы. |
| `Store.java`, `Fetch.java`, `Json.java` | Каталог, подпись, план, загрузка, установка, проверка файлов, очистка. Это чистая Java без классов Android (свой разбор JSON вместо `org.json`), поэтому её проверяет тест на ПК. |
| `Config.java` | Пишется при сборке: открытый ключ из `electron/updater.js` и адрес `https://pennygachi.men/web98/update/`. |
| `Ed25519.java` | Проверка подписи, своя реализация по TweetNaCl (общественное достояние, около 300 строк). Системная проверка Ed25519 есть не на всех версиях Android, которые поддерживает приложение. |
| `ApkUpdate.java` | Загрузка и установка нового APK лаунчера, код из `MainActivity.java` SR98. |
| `assets/launcher/` | Страница лаунчера (`index.html`, `launcher.css`, `launcher.js`), шрифт, значки, снимки и копия каталога на момент сборки для первого запуска без сети. |

Исходники лежат в `tools/parohod98/`, как исходники SR98 для ПК в `tools/sr98-pc/`.

### Папки на телефоне

```text
/data/data/com.win98clone.parohod98/
  files/store/<sha256>          файлы игр по содержимому, один файл на любое число версий
  files/staging/<sha256>.part   недокачанный файл, докачивается по Range
  files/games/<id>.json         установленная версия игры: путь → sha256 и размер
  files/jobs/<id>.json          начатая загрузка: версия, части, файлы, пауза, ошибка, «ждать Wi-Fi»
  files/catalog.json, .sig      последний проверенный каталог
  app_webview/                  localStorage лаунчера и игр (сохранения)
  cache/update/Parohod98.apk       скачанное обновление лаунчера, удаляется при старте
```

Установленная игра — это файл `games/<id>.json`. Он пишется последним, временным файлом и переименованием, когда все файлы игры уже лежат в `store/`. Очередь загрузок — это файлы `jobs/`: после закрытия приложения или остановки службы загрузка продолжается с места обрыва при следующем запуске. Поэтому прерванная установка не оставляет половину игры: на телефоне стоит либо старая версия, либо новая. Журнал установки, как у Win 98, здесь не нужен.

### Адреса страниц

- Лаунчер: `https://appassets.androidplatform.net/launcher/index.html`, файлы из assets APK.
- Игра: `https://appassets.androidplatform.net/games/<id>/index.html`. `GameActivity` находит путь в `games/<id>.json` и отдаёт файл из `store/`. Тип файла определяется по расширению.
- Запрос с `Range` получает ответ 206. Радио GTA перематывает `<audio>` на текущее время суток, без ответа 206 перемотка не работает.
- Адрес у лаунчера и игр один, поэтому localStorage общий. Лаунчер видит ключи сохранений игр и сам переносит их в файл.
- Переходы на чужие адреса внутри WebView запрещены. Ссылки на `https://pennygachi.men/...` и `https://t.me/Penny_Gachimen` открываются во внешнем браузере.

### Запуск игры и возврат

| Шаг | Что происходит |
| --- | --- |
| «Играть» | `Parohod98.play(id)` открывает `GameActivity` с номером игры. |
| Игра открылась | `LauncherActivity` закрывается и уничтожает свой WebView: Forza и GTA получают всю память. Загрузки других игр продолжаются в `App`. |
| «Выход» в меню игры | `Parohod98Game.exit()` снова открывает лаунчер, плакат этой игры выделен рамкой. |
| «Назад» Android | Java вызывает `parohod98Back()`. Игра закрывает своё меню или открывает паузу. В главном меню игры «Назад» спрашивает «Выйти в Пароход 98?». |
| Сворачивание | `parohod98Pause(true)`: игра встаёт на паузу, звук и радио останавливаются. После возврата пауза остаётся, игрок сам нажимает «Продолжить». |
| Страница упала (`onRenderProcessGone`: Android убил страницу из-за памяти) | `GameActivity` закрывается, приложение не падает. На плакате игры: «Игра закрылась: телефону не хватило памяти. Попробуйте графику «Низкая»», кнопка «Сообщить об ошибке». |
| Сброс графики (`webglcontextlost`) | Ни одна из трёх игр его сейчас не обрабатывает. Под флагом `Parohod98` игра показывает «Графика сброшена» и перезагружает страницу. Forza теряет не больше 45 с (автосохранение), Serious Sam начинает уровень заново, GTA загружает последнее сохранение. |

Экран горизонтальный (`sensorLandscape`) и у лаунчера тоже, поэтому при запуске игры экран не поворачивается. В игре экран не гаснет (`FLAG_KEEP_SCREEN_ON`), панели Android спрятаны, вырез экрана занят картинкой, как у SR98.

### Загрузка

| Шаг | Что делает | Если прервать |
| --- | --- | --- |
| Проверка | `update/parohod98/<канал>.json?t=<минута>` и `.sig`, подпись, сравнение с `games/*.json`. Итог по каждой игре: не скачана, последняя версия, есть обновление, нужен новый лаунчер. Итог по лаунчеру: есть новый APK. Не дольше 8 с, иначе «Нет связи» и данные из кэша. | ничего не меняется |
| Перед загрузкой | Свободно на телефоне не меньше загрузки + распакованного размера + 50 МБ (`getUsableSpace`). Сеть: при мобильной сети и загрузке больше 25 МБ лаунчер спрашивает (В6). | — |
| План | Манифест версии и `.sig`. Качаются только sha256, которых нет в `store/`. | — |
| Загрузка | 6 соединений. Файл пишется в `staging/<sha256>.part`, докачка по `Range` с `If-Range`, распаковка gzip и sha256 на лету, при совпадении переименование в `store/<sha256>`. Три попытки на файл с паузой 2, 5 и 15 с. Скорость за последние 3 с, оставшееся время. Пауза и отмена. Поток с низким приоритетом, чтобы не мешать игре. | готовые файлы остаются, `.part` докачивается |
| Установка | `games/<id>.json` временным файлом и переименованием. Если игра сейчас открыта, обновление ставится после выхода из неё. | старая версия на месте |
| Очистка | При старте удаляются файлы `store/`, на которые не ссылается ни одна установленная версия и ни одна начатая загрузка. | — |
| Проверка файлов | sha256 всех файлов игры, повреждённые качаются заново. Без сети только список повреждённых. | ничего не меняется |

Игры качаются по одной, остальные стоят «В очереди». Загрузка продолжается и в свёрнутом приложении (В9): её ведёт служба `DownloadService` (foreground service типа `dataSync`) с уведомлением Android «Пароход 98 · загрузка GTA: Нижний Сити · 61 %» и кнопками «Пауза» и «Отмена». Служба запускается с первой загрузкой и останавливается, когда очередь пуста. Если Android всё же остановил её, при следующем открытии загрузка продолжается с места обрыва.

Разрешение на уведомления (Android 13 и новее) лаунчер спрашивает при первой загрузке, а не при запуске, и объясняет зачем: «Чтобы загрузка шла, когда Пароход 98 свёрнут, Android покажет уведомление». Если игрок отказал, загрузка всё равно идёт, но уведомления не видно, а в свёрнутом приложении Android может её остановить.

### Подпись

- Открытый ключ тот же, что `PUBLIC_KEY` в `electron/updater.js`. Сборка APK берёт его оттуда, второй копии ключа в репозитории нет.
- Каталог, манифесты и «Что нового» принимаются только с верной подписью. Файлы проверяются по sha256 из подписанного манифеста.
- Зачем: код игр работает в WebView приложения. Без подписи взлом мини-ПК или аккаунта Cloudflare дал бы чужой код всем игрокам.
- APK лаунчера Android ставит только с тем же ключом подписи, как у SR98. sha256 из каталога проверяет только целость загрузки.

### Мосты

Мост `Parohod98` есть только у страницы лаунчера, мост `Parohod98Game` только у страницы игры. Игра не может качать файлы и ставить APK.

### Разрешения и версии Android

- Разрешения: `INTERNET`, `ACCESS_NETWORK_STATE` (мобильная сеть), `REQUEST_INSTALL_PACKAGES` (обновление лаунчера), `VIBRATE`, `FOREGROUND_SERVICE` и `FOREGROUND_SERVICE_DATA_SYNC` (загрузка в свёрнутом приложении), `POST_NOTIFICATIONS` (уведомление загрузки на Android 13 и новее). Доступа к файлам телефона нет: файл сохранений игрок выбирает в системном окне.
- `minSdk 26` (Android 8.0). С этой версии есть `onRenderProcessGone` и разрешение на установку обновлений, на старых телефонах эти игры всё равно не потянут. `targetSdk 34`, как у SR98.

## Сервер и выпуск

### Файлы на сервере

```text
update/parohod98/
  stable.json, stable.json.sig        каталог канала stable
  test.json, test.json.sig            каталог канала test
  Parohod98-1.2.apk                      APK лаунчера
  notes.json, notes.json.sig          «Что нового» лаунчера
  serioussam/manifest-1.1.json, .sig  файлы версии игры
  serioussam/notes.json, .sig         «Что нового» игры
  forza/..., gtann/...
update/blobs/                         общие с Win 98 и SR98; снимки и значки игр тоже здесь
```

Файл с версией в имени никогда не перезаписывается: Cloudflare держит старые копии (`LAUNCHER.md`).

### Каталог канала

```json
{
  "format": "win98-update", "v": 1, "product": "parohod98", "channel": "stable",
  "date": "2026-11-12", "commit": "9ab12cd", "blobs": "../blobs/",
  "apk": { "url": "Parohod98-1.2.apk", "versionName": "1.2", "versionCode": 447520, "bytes": 2310000, "sha256": "..." },
  "games": {
    "serioussam": {
      "version": "1.1", "date": "2026-11-10", "minApk": "1.0",
      "manifest": "serioussam/manifest-1.1.json", "notes": "serioussam/notes.json",
      "files": 21, "bytes": 1650000, "download": 520000,
      "title": "Serious Sam 98", "subtitle": "...", "genre": "Шутер от первого лица",
      "tags": ["Орды врагов", "Древний Египет", "Юмор", "Большие арены"], "desc": "...",
      "icon": "a1...", "shots": [{ "sha256": "3f...", "caption": "Песчаный каньон: взрыв камикадзе" }]
    },
    "gtann": {
      "version": "1.0", "...": "...",
      "parts": { "radio": { "title": "Радио в машинах", "files": 8, "bytes": 112951973, "download": 112951973 } }
    }
  }
}
```

- `bytes` — место на телефоне, `download` — сколько качать в сжатом виде.
- `minApk` — самая старая версия лаунчера, которая умеет запускать этот пакет. Если лаунчер старше, игра показывает «Нужен Пароход 98 1.4» и кнопку обновления лаунчера.
- `parts` — части, которые игрок качает отдельно (радио GTA, В3). В манифесте у таких файлов пятое поле: имя части.
- Название, жанр, метки, описание и подписи снимков берутся из `js/game-manager.js` при выпуске, снимки и значок лежат блобами. Новая игра появляется в лаунчере выпуском на сервер, без нового APK, если ей хватает текущего лаунчера.
- Поле `developer` каталога Win 98 («Croteam (2001) / Win 98 Edition» и т. п.) лаунчер не показывает. Это вымысел мира Win 98, а в настоящем приложении он вводил бы в заблуждение. Вместо него строка «Игра проекта Win 98 · фанатский проект Midnight Hearts».

## Пакет игры

`tools/parohod98-game.cjs <id>` (npm `build:parohod98-game`):

1. Читает `forza.html`, `gtann.html` или `serious-sam.html`: скрипты по порядку, стили, встроенный код запуска.
2. Копирует файлы с их путями (`js/apps/forza/fz-core.js` и т. д.).
3. Собирает файлы `content/...`, на которые ссылается код. Сейчас это только радио GTA.
4. Пишет `index.html`: `viewport` для телефона, `window.Parohod98 = { game, version, channel, parts }`, `bugreport-core.js` первым, скрипты игры, `js/touch-controls.js` и модуль игры, шрифты.
5. Шрифты. В Android нет Arial, Impact и Tahoma, WebView подставляет Roboto с другой шириной букв, а вместо Impact обычный шрифт. Пакет кладёт свободные замены с кириллицей и объявляет их под теми же именами через `@font-face`: Arimo вместо Arial, Tahoma, Segoe UI и Trebuchet MS (ширина букв как у Arial), Oswald вместо Impact и Arial Narrow, Montserrat Black вместо Arial Black, Cousine вместо Courier New, PT Serif вместо Georgia и Times New Roman, Neucha вместо рукописных Comic Sans MS, Segoe Print и Brush Script MT. Anton и Archivo Black не подошли: в них нет кириллицы. Файлы лежат в `tools/parohod98/fonts/` (только наборы cyrillic и latin в woff2, 250 КБ, лицензии OFL рядом). Код игр не меняется. Игра запускается после загрузки шрифтов (`document.fonts.load`, не дольше 4 с), иначе надписи, которые рисуются один раз при старте, остались бы другим шрифтом. Сборка находит имена шрифтов в коде и CSS игры и падает на имени без замены.
6. Проверка пакета: страница открывается в headless Edge в режиме телефона через CDP. Каждый запрос получает 200, игра доходит до главного меню, исключений нет.

| Игра | Код | Файлы | Загрузка в gzip |
| --- | --- | --- | --- |
| Serious Sam 98 | 312 КБ, 10 скриптов | нет: текстуры рисуются, звук синтезируется | около 0,1 МБ |
| Forza Horizon: Рига | 1,78 МБ, 34 скрипта, CSS 50 КБ | нет: текстуры рисуются, звук синтезируется, карта внутри `fz-map.js` | 0,5 МБ |
| GTA: Нижний Сити | 3,3 МБ, 47 скриптов | радио: 8 станций, 113 МБ mp3; звуки синтезируются, голоса через `speechSynthesis` | код 1,1 МБ, радио 113 МБ (mp3 не сжимается) |

К каждой игре добавляются шрифты, около 0,3–0,6 МБ. На телефоне одинаковые шрифты хранятся один раз: `store/` хранит файлы по sha256.

## Лаунчер: экраны

### Задачи по частоте

1. Запустить скачанную игру. Это почти каждое открытие, поэтому одно касание: кнопка «Играть» под плакатом.
2. Скачать игру. Один раз на игру.
3. Обновить игру или лаунчер. Редко, видно на плакате и на рейке.
4. Узнать, что за игра: снимки, описание, размер. Перед загрузкой.
5. Прочитать «Что нового».
6. Редко: сохранения, удаление, место, отчёт об ошибке.

### Устройство

- Рейка слева шириной 72 dp: «Библиотека», «Что нового», «Настройки». Телефон лежит горизонтально: высоты мало (320–420 dp), ширины много (640–960 dp). Рейка слева не отнимает высоту у плакатов.
- Библиотека → страница игры → снимок на весь экран.
- «Назад» Android: снимок → страница игры → библиотека → выход из приложения.

Почему так:

- Игр три, и все три видны без прокрутки. Кнопка под плакатом — главное действие этой игры. Касание кадра открывает страницу игры.

- Полоса загрузки стоит в кнопке плаката. Строка под плакатами показывает скорость и остаток текущей загрузки.
- Когда игр станет больше трёх, ряд листается пальцем вбок. Раскладка для семи и больше игр в этот план не входит.

## Частота кадров выше 60 Гц

Решение автора 29.10.2026: игры поддерживают экраны 90 и 120 Гц. Сейчас даже недорогие телефоны продают с такими экранами, например Tecno Spark Go 1 (90 Гц).

Что показал замер: на iQOO WebView отдаёт ровно 60 кадров/с, хотя у экрана частота выше. Android по умолчанию даёт окну приложения 60 Гц, если приложение само не попросило больше.

Что нужно сделать:

- Окно. `GameActivity` выбирает режим экрана с той же шириной и высотой и с самой большой частотой (`Display.getSupportedModes()`, `preferredDisplayModeId`), а на Android 11 и новее ещё сообщает частоту поверхности окна (`Surface.setFrameRate`). Лаунчеру хватает 60 Гц, он ничего не просит.
- Проверка. Окно игры сообщает игре частоту экрана и частоту, которую дал Android (`Parohod98Game.display()`), а замер этапа 2 показывает, дошёл ли `requestAnimationFrame` до 90 и 120 Гц на обоих телефонах. Если система телефона не отдаёт приложению больше 60 Гц (так бывает у прошивок со списком разрешённых игр), это записывается в план и в «Не входит»: обойти прошивку нельзя.
- Шаг игры. Симуляция всех трёх игр остаётся с шагом 1/60 с: на нём держатся физика, ИИ и тесты. Меняется только рисование: позиции рисуются между двумя последними шагами (`k = acc / TICK`).
  - Serious Sam: сейчас между шагами рисуется только камера игрока. Добавляются враги, снаряды, частицы, оружие в руках.
  - Forza: сейчас между шагами рисуется только машина игрока (`renderPose`). Добавляются соперники, поток машин, обломки, камера.
  - GTA: между шагами сейчас не рисуется ничего, на 90–120 Гц картинка обновлялась бы рывками раз в 1/60 с. Добавляются игрок, люди, машины, снаряды, камера.
- Настройка «Частота кадров» в каждой игре: 30, 60, 90, 120 или «Как у экрана» (по умолчанию). 30 и 60 берегут батарею. Ограничение пропускает кадры `requestAnimationFrame`, симуляция не меняется.
- Пресет «Телефон» на сильном телефоне подбирается так, чтобы держать частоту экрана. Если видеокарта не успевает, игра сама не снижает графику: игрок видит частоту в настройках и выбирает сам.
- Тесты: у каждой игры проверка «рисование между шагами»: при кадре 1/120 с позиции на экране меняются каждый кадр, а не через кадр, и симуляция делает ровно 60 шагов в секунду.

## Игры на сенсорном экране

### Опоры

Три правила, по которым выбирается каждая кнопка:

1. «Пальцы дома». Главные действия лежат под большими пальцами и не требуют перехвата телефона.
2. «Плавно». Руль, стик и взгляд аналоговые.
3. «Помощь, а не поддавки». Баланс игры тот же. Помощь живёт во вводе и выключается.

### Общее для трёх игр

- `js/touch-controls.js`: стик (появляется под пальцем), кнопка (касание, удержание, долгое нажатие), область взгляда, ползунок руля, наклон, захват пальца за элементом (`pointerId`), отступы под вырез экрана (`env(safe-area-inset-*)`), левша, прозрачность и размер, отдача через `Parohod98Game.vibrate`. Общие настройки хранит в `parohod98.touch`. Файл один на три игры: все они собирают пульт из одних деталей, а раскладка и вид у каждой свои.
- Сдвиг пальца считается в миллиметрах экрана, а не в пикселях. Тогда поворот одинаков на телефонах с разной плотностью точек.
- Модуль игры (`ss-touch.js`, `fz-touch.js`, `nn-touch.js`) лежит в папке игры. Он подключается в standalone-странице игры (оттуда его берёт пакет), в `index.html` Win 98 не подключается. Включается при `window.Parohod98` или при `?touch` в адресе, для проверки на ПК.
- Модуль игры делает: раскладку по действиям игры, запись во ввод игры, вид в стиле HUD этой игры, подсказку при первом запуске (одна картинка с подписями кнопок, потом её открывает пункт «Управление» в паузе), «Назад», паузу, выход в лаунчер и пресет «Телефон».
- В начале модуля лежит таблица чисел: размеры в мм, мёртвые зоны, чувствительность, конусы и скорости помощи, длительность отдачи. Настройка игры меняет только таблицу, а не код.
- У каждого модуля есть список действий игры по режимам. Тест проверяет, что у каждого действия есть элемент пульта.
- Пульт прячется, когда игрок нажимает настоящую клавиатуру или геймпад, и возвращается при касании, как в SR98.
- Касание пульта сразу пишет состояние, его читает ближайший шаг игры (1/60 с). Нажатая кнопка подсвечивается.
- Звук: все три игры запускают AudioContext только на `keydown` и `mousedown`. Модуль запускает звук на первом касании.
- Графика: у каждой игры два пресета, «Телефон» и «Слабый телефон», первый запуск ставит подходящий (раздел «Замер»). Настройка «Частота кадров» (30, 60, 90, 120, «Как у экрана») и рисование между шагами — раздел «Частота кадров выше 60 Гц».
- Отладка F7 есть на пульте пунктом «Отладка» в меню паузы, только в канале test (В10). Фоторежим GTA (F8) — обычная функция игры, он есть у всех.
- Пульт и HUD не перекрываются: элементы HUD под пальцами переезжают выше.

### Serious Sam 98

Факты:

- 10 скриптов, 312 КБ, файлов нет. WebGL 1, обязательных расширений нет.
- Качество LOW, MED, HIGH = масштаб 0,5, 0,75, 1. Холст = размер × min(2, DPR) × масштаб, ширина не больше 1920.
- Ввод: `input()` в `ss-ui.js` собирает `{fwd, strafe, dyaw, dpitch, jump, walk, fire, weapon, prev, cycle, reload}` для `Game.tick`. Мышь поворачивает взгляд напрямую. `fwd` и `strafe` принимают дробные значения. Касаний, геймпада и помощи в прицеливании нет, прицел только краснеет над врагом.
- Меню на холсте: наведение выбирает пункт, щелчок нажимает, щелчок слева от середины значения уменьшает его.
- «QUIT» появляется только при `onExit`, в standalone выхода нет. `destroy()` освобождает всё.
- Сохранения `ss98-options` и `ss98-save`. Точка сохранения только в начале уровня.
- 5 уровней, 5 сложностей. На «Нормально» 554 врага за игру, в последней волне уровня 5 — 52.

Что важно игроку: ощущение (толпы, большие пушки) и вызов (кружить и стрелять). Главный глагол — двигаться, целиться и стрелять одновременно. На телефоне правый большой палец не может сразу и целиться, и держать кнопку огня. Палец целится хуже мыши.

```text
┌──────────────────────────────────────────────────────────────────┐
│ [||]  ♥ 100  ◈ 50                               [кольт ▸ 6/∞]    │
│                                                                  │
│                          +                                       │
│                                                      [Прыжок]    │
│   ( стик )                                        (( ОГОНЬ ))    │
│  левая половина: движение          правая половина: взгляд       │
└──────────────────────────────────────────────────────────────────┘
```

- Стик в левой половине появляется под пальцем. Отклонение = скорость (`fwd`, `strafe`), мёртвая зона 8 %. Медленный шаг (`walk`) не нужен: достаточно чуть отклонить стик.
- Правая половина: палец тащит взгляд.
- «Огонь» — большая кнопка под правым большим пальцем. Пока палец на ней, его сдвиг тоже поворачивает взгляд: целиться и стрелять можно одним пальцем. Пушка заряжается, пока кнопка нажата, как с мышью.
- «Прыжок» над «Огнём».
- Оружие: значок вверху справа. Касание = следующее оружие, сдвиг влево или вправо = листать, долгое нажатие = список оружия с патронами. Перезарядка появляется только у кольта.
- Пауза вверху слева. NETRICSA (Tab) — пункт меню паузы.
- Здоровье и броня переезжают наверх, чтобы пальцы их не закрывали.
- Помощь прицела (В5), только во вводе, враги и урон те же:
  - «Магнит»: когда враг в конусе 4° от прицела, поворот замедляется до 60 %;
  - «Подводка»: пока «Огонь» нажат и враг в конусе 6°, взгляд плавно доворачивает к нему, не быстрее 8°/с;
  - настройка в меню игры: «Помощь прицела: выкл / слабая / обычная».
- Наклон телефона для прицела — настройка, если датчик работает в WebView (этап 1).
- Отдача: короткая на выстрел пушки и ракетницы, длиннее при ранении.
- Меню: касание = наведение и щелчок, значения «◄ ►» уже меняются половинами строки. Пункты меньше 9 мм под `Parohod98` становятся крупнее.
- «Выход» в главном меню под `Parohod98` вызывает `Parohod98Game.exit()`.
- Сохранение остаётся в начале уровня. Если Android закрыл свёрнутую игру, уровень начинается заново. Сохранение посреди уровня меняет игру и в план не входит. Если на проверке у автора это мешает, решаем отдельно.

### Forza Horizon: Рига

Факты:

- 34 скрипта `fz-*.js` (1,78 МБ) и `forza.css`, всё вместе в gzip 0,5 МБ. Файлов нет.
- WebGL 1, обязательных расширений нет. Пресеты: «Ретро 2000» (без постобработки, сразу на экран), «Высокое» (буферы для свечения и лучей), «Ультра» (тени 2048², стоит по умолчанию). Разрешение 360, 480, 600, 768 или «как у окна», дальность 600, 900 или 1300 м, растительность 0, 1 или 2.
- Ввод: `input()` в `fz-ui.js` сводит клавиши и геймпад в `thr` и `brk` (0..1), `steer` (−1..1) и флаг `analog`, плюс ручник, перемотка, передачи, починка. Аналоговый руль поворачивается со скоростью 7/с, клавиши — 3,4/с от центра и 7/с к центру. ABS, TCS, стабилизация, автомат и помощь руля включены по умолчанию.
- Геймпад уже работает (стандартная раскладка). Касаний нет.
- Меню на DOM: фокус — класс `.fz-focus` на `[data-nav]`, переход по прямоугольникам, наведение выбирает, щелчок нажимает. Размеры в пикселях, без `@media`, окна рассчитаны на 1100×760. HUD масштабируется как `clamp(h / 720, 0.62, 1.25)`.
- Взгляд вокруг: перетаскивание с захватом указателя, 0,0045 рад на пиксель × чувствительность.
- Профиль `fh_riga_profile_v1`, автосохранение каждые 45 с в свободной езде. Фото в standalone живут только в памяти. Охота за фото даёт опыт и кредиты в момент снимка.
- Сборка мира на ПК 1,85 с (рельеф 0,46 с, растительность 0,49 с), +77 МБ памяти JS и +33 МБ буферов. 18 обликов машин потока по 1,75 МБ видеопамяти. Город — 616 кусков, по 3 за кадр.
- Регистрация ставит фокус в поле имени: на телефоне откроется экранная клавиатура.

Что важно игроку: скорость (ощущение), машины, покраска и фото (самовыражение), Рига 2001 года (открытие), гонки с соперниками (вызов). Главный глагол — рулить на скорости. Если руль дёргается, теряется всё остальное, поэтому руль аналоговый.

```text
┌──────────────────────────────────────────────────────────────────┐
│ [≡] [Камера] [Назад] [Фото]                 [◄◄ Перемотка]  мини- │
│                                                            карта │
│   (верхняя половина без кнопок: палец осматривается вокруг)       │
│                               [Событие]          [Ручник]        │
│ ◄════════ руль: палец влево-вправо ════════►  [Тормоз]  [ ГАЗ ]  │
└──────────────────────────────────────────────────────────────────┘
```

- Руль (В4):
  - «Ползунок»: нижние 60 % левой половины. Место касания = центр, сдвиг вбок = поворот, полный поворот на 18 мм (настройка 10–30 мм). Палец отпущен — руль возвращается сам, со скоростью игры 7/с.
  - «Наклон»: угол наклона телефона. Ноль ставится при старте и кнопкой «Выровнять», полный поворот на 25° (настройка), мёртвая зона 2°.
  - «Кнопки»: ◄ и ► слева, руль ведёт себя как с клавиатуры (3,4/с).
- Педали справа: «Газ» у края, «Тормоз» левее. Это одна зона: палец перекатывается с тормоза на газ, не отрываясь. Тормоз на месте сам включает задний ход, это уже есть в игре.
- «Ручник» над тормозом.
- Сверху: пауза, «Камера», «Назад» (смотреть назад, пока палец держит кнопку), «Фото», «Перемотка» (держать, видна только когда перемотка доступна).
- По месту: «Событие» вместо Enter, когда событие ближе 30 м; «Починить» (держать), когда машина помята; «▲» и «▼», только при ручной коробке.
- Фары, гудок, радио и «Вернуть на дорогу» лежат в меню паузы и в коротком ряду «Ещё» у паузы.
- Касание мини-карты открывает карту.
- Палец на верхней половине экрана вне кнопок осматривается вокруг, через тот же путь, что мышь (`ui.look`).
- «Автогаз» (настройка, выключен): газ нажат всегда, кроме тормоза, ручника, перемотки и меню. Тогда правый палец свободен для тормоза и ручника.
- Отдача: удары из журнала ударов игры (сила по удару), переключение передачи.
- Спидометр и тахометр поднимаются над педалями. Нижняя граница масштаба HUD на телефоне выше 0,62: при высоте экрана 360 dp цифры иначе слишком мелкие.
- Меню (этап 8): `fz-touch.css` под `Parohod98` даёт строкам не меньше 9 мм высоты, списки листаются пальцем, вкладки переключаются касанием заголовка. Касание уже выбирает и нажимает пункт (наведение и щелчок). Каждый экран проверяется снимками `tools/forza-shots.cjs` в режиме телефона 800×360 и 640×360.
- Карта: сдвиг пальцем, щипок для масштаба, касание ставит курсор, кнопки «Метка» и «Переместиться».
- Регистрация: поле имени поднимается над экранной клавиатурой Android.
- Фоторежим: стик двигает камеру, палец поворачивает её, щипок меняет объектив, кнопки «Снять», «Вверх», «Вниз», «Скрыть», «Выход». Охота за фото работает, награда даётся в момент снимка. Снимки живут в памяти, пока открыта игра, как в standalone.

### GTA: Нижний Сити

Факты:

- 47 скриптов `nn-*.js` (3,3 МБ) и радио: 8 станций, 113 МБ mp3. Звуки синтезируются, текстуры рисуются, голоса идут через `speechSynthesis`.
- Только WebGL 2: массив из 146 текстур, 32-битные индексы, MSAA, блиты. RGBA16F необязателен. Обработчика сброса графики нет.
- Сборка на ПК: город 2,6 с и 334 МБ памяти, геометрия 1,5 с, около 207 МБ сеток уходит в видеопамять, во время сборки создаётся до 565 МБ буферов. Это главный риск на телефоне.
- Настройки: эффекты (высокие, низкие), масштаб 0,4–1,0, дальность 0,5–1,5, детали машин и города, плотность машин и людей 0,2–1,6. Холст = размер × масштаб × min(DPR, 2).
- Ввод: `buildInput()` в `nn-ui.js` раз в 1/60 с собирает `inp`: `fwd`, `right`, `steer`, `sprint`, `jump`, `fire`, `aim`, `enter`, `reload`, `slot`, `horn`, `driveBySide`, `camYaw`, луч прицела и другие поля. Симуляция принимает дробные значения: отклонение стика = скорость (шаг 1,6, бег 4,3, рывок 6,6 м/с), руль и газ ±1. Прицел — луч из центра камеры, помощи в прицеливании нет.
- Меню на DOM (`mouseenter`, `mousedown`). Карта — вкладка паузы, её двигают и масштабируют. Сценки листаются пробелом или щелчком, X пропускает все. Миссия начинается входом в маркер.
- Сохранения `gtann_settings`, `gtann_save_1`…`gtann_save_4`, `gtann_photos`. Снимки фоторежима в standalone живут только в памяти.
- Шрифты Arial, Impact, Arial Black.
- Звук: AudioContext создаётся при новой игре и на `mousedown`. Радио — `<audio>` с позицией по часам. При потере фокуса игра не встаёт на паузу.

Что важно игроку: фантазия (бандит в Нижнем Новгороде 2000 года), открытие (Автозаводский район 1:1), ощущение (погони и стрельба), сюжет (10 миссий). Режимов два, пешком и в машине, у них разные глаголы. Пульт меняется сам, когда игрок садится в машину или выходит.

Пешком:

```text
┌──────────────────────────────────────────────────────────────────┐
│ [||] [Вид]   $ 1200   ★★☆☆☆                  [АКМ 30/90 ▸]  мини- │
│                                                            карта │
│                           +                       [Перезар.]     │
│                                       [Сесть]  [Прыжок]          │
│   ( стик )                                 [Прицел] (( ОГОНЬ ))  │
│  левая половина: движение          правая половина: камера       │
└──────────────────────────────────────────────────────────────────┘
```

- Стик в левой половине появляется под пальцем. Отклонение = скорость от шага до бега, симуляция уже это умеет. Палец за краем кольца = рывок (6,6 м/с). Левый палец занят стиком, правый камерой, поэтому рывок не стал отдельной кнопкой.
- Правая половина: палец поворачивает камеру.
- «Огонь»: держать = стрелять. Сдвиг пальца на кнопке тоже поворачивает камеру. С метательным оружием: держать = заряд, отпустить = бросок, увести палец на «✕» = отмена (R на ПК).
- «Прицел» — переключатель, вид через плечо, как правая кнопка мыши. Помощь прицела (В5): при включении прицел цепляется к ближайшей видимой цели в конусе 10°, пока «Огонь» нажат, ведёт её не быстрее 20°/с, сдвиг пальца по «Огню» вбок переключает цель.
- «Прыжок». «Сесть» появляется у машины (F на ПК). «Задание» (T) и «Пропустить поездку» (X) появляются, когда доступны.
- Оружие: значок вверху справа. Касание = следующее, сдвиг = листать, долгое нажатие = круг из 9 ячеек.
- «Перезарядка» появляется, когда магазин не полон.
- «Вид» (C) вверху. Касание мини-карты открывает карту.

В машине:

```text
┌──────────────────────────────────────────────────────────────────┐
│ [||] [Вид] [Радио: WAVE]  $ 1200  ★★☆☆☆      [Выйти]   мини-карта │
│                                                                  │
│                                      [Гудок] [Назад]             │
│                                   [◄ огонь ►]   [Ручник]         │
│ ◄═══════ руль, как в Forza ═══════►            [Тормоз] [ ГАЗ ]  │
└──────────────────────────────────────────────────────────────────┘
```

- Руль и педали — те же детали `touch-controls.js` и та же настройка руля, что в Forza (В4).
- «Выйти» (F): медленнее 2,5 м/с — выход, быстрее 8 м/с — прыжок из машины. Решает игра, как сейчас.
- «Радио»: касание = следующая станция, долгое нажатие = список станций.
- «◄ огонь ►»: стрельба из окна влево или вправо (Q/E и левая кнопка мыши на ПК), только с подходящим оружием.
- Танк и БТР: «Пушка» и «Пулемёт», башню поворачивает палец на правой половине.
- «Назад» (B) — смотреть назад, «Гудок» (H).

Остальное:

- Сценки: касание = следующая реплика, «Пропустить» = все сразу (X).
- Меню паузы и карта: касание выбирает и нажимает, пункты крупнее под `Parohod98`. Карту двигает палец, масштаб меняет щипок.
- Фоторежим (F8): стик двигает камеру, палец поворачивает её, щипок меняет объектив, кнопки «Снять», «Вверх», «Вниз», «Скрыть», «Выход». Снимки живут в памяти, пока открыта игра. Пункты «Сделать обоями» и «Открыть в просмотрщике» под `Parohod98` спрятаны: без Win 98 их нет.
- Голоса: если в WebView нет `speechSynthesis`, мост `Parohod98Game.speak` говорит через Android TextToSpeech русским голосом телефона.
- Радио (В3): запускается после первого касания, при сворачивании останавливается (`pause()`). Если часть «Радио» не скачана, станций нет в списке, а в машине тихо.
- Сворачивание ставит игру на паузу. Сейчас при потере фокуса GTA продолжает идти.
- Сохранение при сворачивании: если в меню можно сохраняться где угодно, при сворачивании вне миссии игра пишет отдельную ячейку «Авто». Это проверяется по коду `nn-game.js` на этапе 10.
- Графика «Телефон»: эффекты низкие, масштаб 0,5–0,7, дальность 0,6, детали города низкие, плотность 0,5. Точные числа после замера. Если MSAA на телефоне дорого, в настройках появляется «Сглаживание: выкл».
- Память. Если замер покажет падения страницы, перед этапом 9 вставляется этап «Память GTA на телефоне» с отдельным планом: сборка города кусками, освобождение буферов сразу после передачи в видеопамять, меньший город вокруг игрока.

## Сохранения

- Сохранения лежат в localStorage WebView приложения. Обновление игры и лаунчера их не трогает. Удаление самого приложения Android стирает их, об этом предупреждает экран «Сохранения».
- Ключи по играм берутся из `backup-catalog.js`: Forza `fh_riga_*` и `fh_photo_probe`, GTA `gtann_*`, Serious Sam `ss98-*`.
- Страница игры → «Сохранения»:
  - размер сохранений;
  - «Сохранить в файл»: `Parohod98-<id>-<ДДММГГГГ>.json`, формат `{ "format": "Parohod98-saves", "v": 1, "game": "forza", "version": "1.2", "date": "...", "keys": { ... } }`;
  - «Загрузить из файла»: свой формат, файл «Архивации данных» Win 98 (`Win98Backup`, берутся только ключи этой игры) и простой JSON `{ ключ: значение }`. Перед перезаписью экран подтверждения;
  - «Удалить сохранения» с подтверждением.
- Так прогресс переезжает с ПК на телефон и обратно: Win 98 → «Архивация данных» → файл → телефон, а файл с телефона открывается там же кнопкой «Открыть файл...».
- Квота localStorage около 5 млн знаков на адрес. GTA уже отказывает снимку, если всё вместе выйдет больше 4,5 млн знаков. Замер на этапе 1 показывает, сколько занимают сохранения трёх игр после часа игры.

## Отчёты об ошибках

- Лаунчер: «Настройки» → «Сообщить об ошибке». Игры: пункт «Сообщить об ошибке» в меню паузы, с настоящей клавиатурой ещё F10.
- Окно отчёта общее для лаунчера и трёх игр, в стиле Пароход 98, поверх игры: заголовок, текст, вид ошибки, как часто повторяется, кадр с рамками, которые игрок обводит пальцем, галочка «Приложить сохранение». Ядро то же: `bugreport-core.js` и `bugreport-shot.js`.
- `source: 'parohod98'`, `channel: 'parohod98-apk'`, `where.app` = игра или `launcher`. «Где» даёт модуль игры: Forza — событие, место, время суток; GTA — миссия и координаты; Serious Sam — уровень и волна.
- Приёмка: строка «Пароход 98» в Telegram и на странице приёмки (`tools/bugs/receiver.cjs`). Обновляет её автор, как написано в `AGENTS.md`.
- `node tools/bugs.cjs repro <id>` для `parohod98` открывает пакет игры в headless Edge в режиме телефона с сохранением из отчёта.
- `bugs.cjs status <id> fixed --in next`: выпуск игры ставит номер вида «Forza 1.3».

## Проверка на телефоне

У Claude нет телефона. Логику и вид проверяет Edge с эмуляцией телефона и касаний (CDP `Emulation.setTouchEmulationEnabled`, `Input.dispatchTouchEvent` с несколькими пальцами). Ощущение от управления проверяется только на телефоне. Поэтому этапы с управлением закрываются только после проверки автором.

Как проверять:

- Задания этапа написаны в нём, например «пройти уровень 1 Serious Sam на «Нормально» только касаниями».
- Если можно, автор даёт телефон человеку, который не видел игру, и первые 10 минут молча смотрит: где тот застрял, что нажимал зря, где спорил с камерой. Подсказывать нельзя: первое впечатление бывает один раз.
- Что записывать: прошёл ли задание, время, смерти, что нажимал не туда, когда устал палец. Ошибки и кадры отправляются отчётами (с этапа 6), их Claude забирает `bugs.cjs pull`.
- В план записывается только то, что видели на телефоне. Предположения туда не идут.

## Безопасность и приватность

- Лаунчер только качает файлы. Об игроке ничего не отправляется, кроме отчёта, который игрок сам отправил.
- Подпись Ed25519 у каталога, манифестов и текстов, sha256 у каждого файла, HTTPS.
- Мост загрузки и установки есть только у страницы лаунчера. У игры мост узкий: выход, отдача, наклон, голос.
- Загрузки идут только с `https://pennygachi.men/web98/update/`. Переходы WebView на чужие адреса запрещены.
- Файлы телефона лаунчер не читает: файл сохранений игрок выбирает сам в системном окне.
- Ключ подписи APK и ключ выпусков хранятся вне git, копии у автора.

5. Свернуть игру вне миссии, закрыть приложение, загрузить «Автосохранение».

- Пульт в машине (руль и педали из `touch-controls.js`, «Выйти», радио, стрельба из окна, танк и БТР, гудок, взгляд назад).

- Задания на телефоне: все 10 миссий, хотя бы по разу каждый вид транспорта.

Готово, когда: игра проходится от начала до конца касаниями на телефоне автора.

### Этап 11. Сохранения и место

Код сделан 30.10.2026, ждёт проверки на телефоне.

- Экран «Сохранения» со страницы игры, он есть и у нескачанной игры: размер и число записей, «Сохранить в файл» (`Parohod98-<id>-<ДДММГГГГ>.json`), «Загрузить из файла», «Удалить сохранения» с подтверждением, подсказка о переносе с ПК и предупреждение об удалении приложения.
- `launcher-state.js`: чистые функции `readSaves`, `packSaves`, `parseSaves` (`Parohod98-saves`, `Win98Backup` и простой JSON, всегда только ключи этой игры; файл другой игры и чужой файл называются своими ошибками), `writeSaves` (заменяет только ключи этой игры, при нехватке места возвращает старые).
- `LauncherActivity.java`: `saveFile`, `openFile`, `takeFile` через системное окно файлов (SAF), файл до 32 МБ. Разрешения на файлы не нужны. Текст файла забирается через мост `takeFile`, а не через `evaluateJavascript`.
- Перед заменой существующих сохранений экран подтверждения. В удалении игры появилась кнопка «Удалить и сохранения»; просто «Удалить» их оставляет.
- «Место» в настройках: файлы и сохранения каждой игры, свободно на телефоне. «Проверить файлы» уже есть на странице игры (этап 5).
- Настройки с ПК не мешают: пресет телефона ставится заново, если в файле его нет (`tpreset`).
- Перенос обратно: файл с телефона открывается в Win 98 → «Архивация данных» → «Открыть файл...» (`convertForeign` в `js/apps/backup-catalog.js`). Берутся только ключи этой игры. Настройки графики и пульта остаются с ПК: `gtann_settings` и `ss98-options` не заменяются, в профиле Forza поля графики, плотность машин и настройки пульта берутся из профиля ПК. Автосохранение GTA (`gtann_save_5`) занимает свободную ячейку, а если все четыре заняты, заменяет самую старую, когда оно новее. Часть в Win 98 дойдёт до игроков со следующим выпуском Win 98.
- `tests/parohod98-launcher.test.js` (17): архив Win 98 даёт только ключи своей игры, свой файл читается обратно, чужие и испорченные файлы отклоняются, замена не трогает другие игры, при переполнении старые сохранения остаются, ключи совпадают с `backup-catalog.js` и окном отчёта. Снимки экрана и окна подтверждения в `tools/parohod98-shots.cjs`.
- В канале test: Пароход 98 1.7.

Задание на телефоне:

1. Обновить Пароход 98 до 1.7.
2. На ПК: Win 98 → «Архивация данных» → файл с Forza. Перенести файл на телефон.
3. Forza → страница игры → «Сохранения» → «Загрузить из файла». Запустить игру: профиль с ПК на месте.
4. «Сохранить в файл»: файл появился там, где выбрали.
5. Перенести этот файл на ПК: Win 98 → «Архивация данных» → «Открыть файл...» → восстановить. Прогресс с телефона на месте, графика как была на ПК.

- «Сохранения» на странице игры: размер, в файл, из файла (`Parohod98-saves`, `Win98Backup`, простой JSON), подтверждение перезаписи, удаление.
- «Место» в настройках, «Проверить файлы» на странице игры.
- Тест: файл из «Архивации данных» Win 98 даёт телефону ключи только своей игры.
- Задание на телефоне: перенести профиль Forza с ПК (Win 98) на телефон и обратно в файл.

Готово, когда: профиль Forza с ПК открылся на телефоне автора.
