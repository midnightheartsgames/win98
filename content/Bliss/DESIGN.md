# «Безмятежность» — полёт над холмом

Живой одностраничный дизайн-документ. Растёт только там, где принято реальное решение.

## Крючок

Вы оказываетесь внутри самых известных обоев рабочего стола: зелёный холм, синее небо, кучевые облака. Только теперь можно оторваться от земли и полететь.

Первый кадр игры повторяет композицию обоев. Узнавание должно случиться раньше, чем игрок прочтёт хоть одно слово.

## Целевая эстетика (MDA)

| Эстетика | Чем достигается |
| --- | --- |
| **Ощущение (sensation)** | Крен в поворотах, разгон в пикировании, рост FOV, ветер в ушах, трава расступается под вами. |
| **Покорность / отдых (submission)** | Нет поражения, таймеров и врагов. Разбиться нельзя: земля мягко отталкивает. |
| **Открытие (discovery)** | Пять «видоискателей» в мире. Пролёт сквозь видоискатель снимает кадр-обои. |

Чего мы сознательно **не** даём: соревнования, счёта очков, давления временем.

## Столпы

1. **Ни одного провала.** Любое действие игрока безопасно.
2. **Полёт приятен сам по себе.** Даже без целей в пустом небе управление должно радовать.
3. **Узнаваемо с первого кадра.** Холм, небо и облака — главный герой.

Каждая новая фича обязана служить хотя бы одному столпу, иначе она вырезается.

## Глаголы

- **Лететь** (мышь задаёт направление, птица плавно доворачивает с креном).
- **Пикировать / набирать высоту** — обмен высоты на скорость. Нырок со склона разгоняет.
- **Взмахнуть** (W / Shift) — ускорение. **Тормозить** (S).
- **Парить в потоке** — восходящий термик поднимает к облакам без усилий.
- **Снять кадр** — пролететь сквозь видоискатель.

## Петли

```text
секунды   нырок со склона → разгон → крен над травой → подъём  (ощущение)
минуты    увидеть ориентир → долететь → поймать кадр            (открытие)
сессия    собрать 5 кадров → «золотой час» → сохранить обои     (награда)
```

Награда каждого слоя питает следующий: скорость от нырка помогает долететь до ориентира, кадры заполняют альбом, полный альбом меняет мир (солнце садится, свет становится золотым) и даёт сохранить свои обои в 1920×1080.

## Метрики игрока (зафиксированы до геометрии)

Единица — метр. Все размеры уровня строятся от этих чисел. Значения живут в `TUNING` в [js/world.js](js/world.js).

| Параметр | Значение | Зачем |
| --- | --- | --- |
| Минимальная скорость | 9 м/с | Сваливания нет — столп «ни одного провала». |
| Крейсерская | 16 м/с | Птица сама поддерживает её взмахами. |
| Взмах (W) | до ~30 м/с | Горизонтальный разгон. |
| Пикирование | до ~70 м/с | Главное «ощущение». |
| Мин. просвет над землёй | 1,8 м | Скольжение по траве без касания. |
| Радиус термика | 70 м, подъём до 6,5 м/с | Удваивает скороподъёмность, но не обязателен. |
| Нижняя граница облаков | ~320 м | Достижима за минуту набора. |
| Мягкая граница мира | 2,5 км от центра | Ветер разворачивает к долине. |
| Видоискатель | 16×9 м | Пропорция экрана; виден за 800 м. |

### Зоны

| Зона | Роль в уровне |
| --- | --- |
| **Главный холм** | Ориентир («weenie») всей долины. Гладкий, без деревьев, виден отовсюду. С юга его гребень — это линия горизонта, как на обоях. |
| **Стартовый луг** | Безопасное место для обучения. Склон плавно поднимается к гребню. |
| **Дорога** | Золотой путь вдоль долины. Связывает виноградники, старт и одинокий дуб — три кадра из пяти. |
| **Виноградники** | Ряды направлены точно на главный холм: сходящиеся линии ведут взгляд. |
| **Одинокий дуб** | Второй ориентир на восточном пригорке. Силуэт на фоне неба. |
| **Дубовая роща** | Тёмные деревья на северо-западе — как в левом нижнем углу обоев. |
| **Термики** | Под шапками кучевых облаков, отмечены кружащими ястребами и пухом, который поднимается столбом. |
| **Горы** | Естественная граница. Тают в дымке. |

## Пять кадров: введение → развитие → поворот → комбинация → секрет

| # | Кадр | Где | Чему учит |
| --- | --- | --- | --- |
| К1 | «Безмятежность» | Прямо на пути после взлёта | **Введение.** Игрок пролетает сквозь него через 5 секунд почти без усилий и узнаёт, что делают видоискатели. |
| К2 | «Одинокий дуб» | Восточный пригорок, вдоль дороги | **Развитие.** Нужно найти ориентир и прилететь к нему. |
| К3 | «Виноградники» | Низко между рядами | **Поворот.** Нужен точный полёт у самой земли. |
| К4 | «Над облаками» | Над шапкой термика Т1, ~500 м | **Комбинация.** Набор высоты, термик, навигация. |
| К5 | «Облачное окно» | В арке облака на северо-западе | **Секрет.** Странная форма облака видна уже с титульного кадра. Это хлебная крошка. |

Порядок не навязан: все кадры видны или угадываются с открытого неба. Подсказки в альбоме загадочные, без стрелок и карты.

## Ведение игрока без стрелок

- **Свет.** Солнце сзади-слева от стартового взгляда, склон холма ярко освещён.
- **Ориентиры.** Холм в центре, дуб на востоке, горы по краю.
- **Акцентный цвет.** Тёплое золото используется **только** для видоискателей. Больше нигде.
- **Хлебные крошки.** Птицы над термиками, дорога вдоль долины, ряды винограда, облако с дырой.

## Кривая интенсивности

Игра спокойная, поэтому «пики» — это не опасность, а вспышки ощущений: нырок, облако, вершина. Между ними — долгое парение.

```text
интенсивность
  ▲          нырок           облако         над облаками      золотой час
  │           /\              /\               /\                 ___
  │   взлёт  /  \   парение  /  \   термик    /  \   спуск       /
  │  /\_____/    \__________/    \___________/    \_____________/
  └──────────────────────────────────────────────────────────────▶ время
```

## Звук

Простой процедурный эмбиент на Web Audio, без файлов.

| Слой | Поведение |
| --- | --- |
| Фоновый ветер | Розовый шум, медленные порывы. Всегда. |
| Ветер полёта | Громкость и высота фильтра растут со скоростью. В крене громче в «наружном» ухе. |
| Свист | Появляется только в быстром пикировании. |
| Трава | Шуршание, когда летите ниже 6 м. |
| Термик | Низкий гул, пока поток поднимает. |
| Облако | Внутри облака всё глохнет (фильтр низких частот). |
| Птицы | Чириканье, свист, трель жаворонка; ястреб — у термиков. Тише с высотой. |
| Затвор, колокольчики | Обратная связь на кадр и на полный альбом. |

## Ощущение полёта (juice)

- Крен пропорционален скорости поворота, до 55°.
- FOV растёт с 60° до 76° на скорости.
- Пух и пыльца пролетают мимо камеры — главный индикатор скорости.
- Трава расступается под низко летящей птицей.
- Вход в облако: белая пелена, глухой звук.
- Кадр: щелчок затвора, вспышка, фото улетает в альбом.

## Объём

**Входит:** одна долина, 5 кадров, 3 термика, ~40 облаков, ~50 дубов, дорога, виноградники, процедурный звук, альбом с сохранением обоев, золотой час, авто-качество.

**Не входит:** смена погоды, ночь, вода, вид от третьего лица, мультиплеер, полноценное мобильное управление (есть только перетаскивание пальцем).

## Устройство кода

Чистый WebGL 2 без библиотек и сборки: `index.html` открывается двойным кликом.

| Файл | Что внутри |
| --- | --- |
| [js/world.js](js/world.js) | `TUNING`, палитры, функция рельефа `H()`, раскладка ориентиров, облака, термики, кадры. **Уровень правится здесь.** |
| [js/render.js](js/render.js) | GPU-ресурсы, отрисовка сцены с любой камеры, снимки кадров. |
| [js/shaders.js](js/shaders.js) | GLSL: небо, земля, трава, деревья, облака, птицы, видоискатели. |
| [js/flight.js](js/flight.js) | Ввод и модель полёта. |
| [js/audio.js](js/audio.js) | Процедурный звук. |
| [js/main.js](js/main.js) | Состояния, альбом, подсказки, авто-качество, главный цикл. |

В консоли браузера доступен `__bliss` (например, `__bliss.setGolden(1)` — сразу включить золотой час).

## Что проверять на плейтесте

Смотреть молча, не подсказывать.

- Сколько секунд до первого кадра (цель: меньше 10).
- Находит ли игрок термик без подсказки (смотреть, летит ли он к птицам).
- Видит ли игрок облачное окно с титульного кадра.
- Где игрок упирается в мягкую границу (значит, там пусто и скучно).
- Как долго игрок летает без цели после сбора альбома (это мера столпа №2).
