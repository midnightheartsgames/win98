# «Аватар: Тихий цикл» — сюжетные флаги демо (Глава 1)

Этот файл — контракт между демо и будущими главами. Любой флаг из списка
может быть прочитан Главой 2 из «чистого сохранения» (`clean: true`), которое
предлагается записать на экране «Продолжение следует».

Флаги хранятся в `SaveData.flags` (объект `имя → true`). Числа — в `vars`,
доверие — в `trust.tao / trust.miri / trust.pipo` (−5…10), задания — в `quests`
(номер текущего шага, завершено = число шагов + 1).

Условия в данных пишутся строкой: `hana_farewell && !ferry_boarded`,
`trust.tao >= 3`, `quest.dog > 2`, `item.kupol_pass`, `party.miri`, `radio.numbers`,
`paisho.wins >= 3`, `secrets`, `gold`.

## Служебные

| Флаг | Где ставится | Смысл |
|---|---|---|
| `game_started` | движок | Новая игра запущена, стартовое событие уже отработало |
| `attract` | титул | Демонстрационный показ видения (не сохраняется) |

| `chapter2_unlocked` | `finale_scene` | Открывает узел «Южный храм воздуха» на карте мира |

## Что стоит прочитать Главе 2

* `trust.tao`, `trust.miri`, `trust.pipo` — отношения и какая сцена сыграла на крыше.
* `guardian_defeated` — у Исы есть «Сердце хранителя»; хранитель может помнить её.
* `secret_open`, `radio_secret` — игрок знает о «Пустом эфире».
* `quest.*` — кто из горожан ей обязан (Тоши, Кен, бабушка Оу).
* `paisho_xiao` — у Исы есть Белый лотос (фишка) и Знак Отпора.
* `diary_4` / предмет `jinhai_pages` — источник знаний о «тишине цикла».
